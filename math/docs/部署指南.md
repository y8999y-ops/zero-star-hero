# 《魔數學院》動態網站部署指南（Cloudflare Workers + D1）

本指南說明如何免費把《魔數學院》遊戲＋學生雲端存檔＋教師管理後台（`/admin`）部署到 Cloudflare。

## 1. 本地先試玩與測試後台

不用申請任何帳號，在 `math/` 目錄直接執行：

```bash
npm run dev:cloud
```

- 遊戲網址：`http://localhost:8787/math/`
- 教師後台：`http://localhost:8787/admin/`（本地預設密碼 `1234`，可在 `worker/.dev.vars` 寫 `ADMIN_PASSWORD=你的密碼` 自訂）
- 流程試跑：
  1. 打開 `/admin/` 登入 → 到「班級與學生管理」建立班級（如 `402`／`四年二班`）並批量貼上學生名單（格式：`組別,座號,姓名`，例如 `1,07,王小明`）。
  2. 點「列印登入小卡」或複製專屬連結，貼到遊戲網址或點標題頁右上角「學生代碼登入」。
  3. 進戰鬥答幾題（含答錯），回 `/admin/` 按「重新整理」，就能即時看到遊玩時間、次數、未畢業錯題本與完整錯題明細！

---

## 2. 免費部署到 Cloudflare（約 5 分鐘）

### 前置準備
1. 註冊一個免費的 [Cloudflare](https://dash.cloudflare.com/) 帳號。
2. 在 `math/` 目錄登入 Wrangler（使用 `npx`，不需全域安裝）：
   ```bash
   npx wrangler login
   ```

### 步驟一：打包靜態檔案（含 `math/`、`admin/`、`pixelfx/`）
```bash
npm run pack
```
這會產生乾淨的 `dist/` 資料夾。

### 步驟二：建立免費 D1 資料庫並套用資料表
```bash
npx wrangler d1 create mosu-db
```
指令會印出一組 `database_id`，把它貼到 [worker/wrangler.toml](../worker/wrangler.toml) 的 `database_id = "..."` 位置。

接著初始化雲端資料表：
```bash
npx wrangler d1 execute mosu-db --remote --file=worker/schema.sql --config worker/wrangler.toml
```

### 步驟三：設定教師後台密碼（Secret）
```bash
npx wrangler secret put ADMIN_PASSWORD --config worker/wrangler.toml
```
輸入你想設的教師密碼（不會寫進程式碼或 Git）。

### 步驟四：部署上線！
```bash
npx wrangler deploy --config worker/wrangler.toml
```
部署完成後 Wrangler 會印出你的網站網址（例如 `https://mosu-academy.<你的帳號>.workers.dev`）：
- 給學生玩：`https://你的網址/math/`（或直接發後台列印的 QR Code 登入小卡）
- 教師後台：`https://你的網址/admin/`

> 之後每次修改遊戲程式，只要跑兩行即可更新：
> ```bash
> npm run pack
> npx wrangler deploy --config worker/wrangler.toml
> ```

## 3. 自動部署：推上 GitHub 就自動更新（Cloudflare Workers Builds）

設定一次之後，每次 `git push` 到 `main`，Cloudflare 會自己打包、更新資料表、部署，不用再手動跑指令。全部在 Cloudflare 網頁上點，不用在 GitHub 存任何金鑰。

### 步驟一：建立 D1 資料庫（只做一次）
1. Cloudflare 後台左邊 **Storage & Databases → D1 SQL Database → Create**。
2. 名稱填 `mosu-db` → Create。
3. 複製畫面上的 **Database ID**，貼到 [worker/wrangler.toml](../worker/wrangler.toml) 的 `database_id`，推上 GitHub。
   （資料表不用自己建：每次部署都會自動跑 `worker/schema.sql`，裡面都是 `IF NOT EXISTS`，重跑不會清資料。）

### 步驟二：連接 GitHub
1. **Workers & Pages → Create → Import a repository**（或「Connect to Git」），授權 GitHub，選 `zero-star-hero`。
2. 設定：

   | 欄位 | 填 |
   |---|---|
   | Project name | `mosu-academy`（要跟 wrangler.toml 的 `name` 一樣） |
   | Production branch | `main` |
   | Root directory（Path） | `math` |
   | Build command | `npm run pack` |
   | Deploy command | `npm run deploy` |

3. 儲存並部署。第一次會跑一兩分鐘，完成後網址是 `https://mosu-academy.<你的帳號>.workers.dev`。

### 步驟三：設定教師密碼（只做一次）
Worker → **Settings → Variables and Secrets → Add** → 類型選 **Secret**，名稱 `ADMIN_PASSWORD`，值填你的密碼 → Deploy。之後自動部署不會蓋掉它。

### 之後
- 改遊戲 → `git push` → 約 1～2 分鐘後網站更新。建置紀錄在 Worker 的 **Deployments / Builds** 分頁看。
- GitHub Pages 的靜態版（`github.io/zero-star-hero/math/`）照常可以玩，只是沒有雲端存檔與後台（程式會自動退回本機存檔）。
- 打包時會自動抓 `pixelfx` 子模組；抓不到會讓建置失敗，不會部署壞掉的版本。
