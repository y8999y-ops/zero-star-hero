## 1. 核心主題

**「數學是一種魔法。」**

在這個世界裡，數學不是課本上的功課，而是**真正的魔法**：加法能讓果實結得更多，乘法能讓魔法陣一次複製好幾圈，分數能把一塊魔晶公平地分給大家，方程式能找出藏起來的未知寶物。**懂一條數學，就學會一道魔法。**

由這個主題延伸出三件事，故事、台詞和題目情境都要守住：
1. **生活裡處處是魔法**：買東西、分東西、量距離、算時間，在這個世界裡都是在使用魔法。所以每一道題目都是這個世界裡真的會發生的事（見第 9 節）。
2. **算錯只是咒語沒成形**：算式寫錯不會爆炸，只會「啪」一聲散掉，再寫一次就好。遊戲不羞辱、不嚇人，一直鼓勵再試一次。
3. **放棄才是真正的敵人**：怪物是「被放棄的題目」變成的墨水，只要有人把那題算完，就能淨化它。

## 2. 世界：數律之地

- 這片大地上的一切都照「**數律**」運作：花開幾瓣、潮水幾點漲、星星怎麼排，背後都是數字。
- 魔法就是把數律**寫出來**：魔數師用魔杖在空中寫下算式，**算式成立的那一刻**，魔力才會釋放。
- 每一種數學都是一個魔法分支，例如加減是「增減術」、乘除是「倍分術」、分數是「分晶術」、方程式是「解謎術」。最厲害的大魔法，往往就是最漂亮的那一條算式。
- 一般居民也會一點小魔法：麵包師用乘法一次烤好幾盤，商人用加減找零錢，農夫用面積魔法規劃田地。魔數學院專門培養能處理更難的數學、更大魔法的**魔數師**。

## 3. 魔數學院

- 建在一座**緩緩旋轉的浮空島**上，整座島像一個巨大的齒輪鐘，島上每個區域依刻度排列。
- 每年春天，滿 7 歲的孩子都可以來入學。沒有入學考試，只有「**共鳴儀式**」（見第 5 節）。
- 校訓刻在大門上：**「每一題，都值得被算完。」**

### 3.0 島上的地方

- **浮空船碼頭**：新生搭浮空船抵達的地方，在島的邊緣。
- **中央廣場**：島的正中央，有共鳴之井，院長常在這裡散步。
- **五座學系學院**：繞著廣場排成一圈——赤焰塔（紅磚高塔，屋頂有不滅的火盆）、蒼流館（藍瓦屋頂，旁邊有噴泉水道）、白霜堂（白石建築，屋簷掛著冰晶）、翠森苑（樹屋與溫室相連，牆上爬滿藤）、紫雷閣（尖頂樓閣，避雷針上常有電光）。
- **學系宿舍**：每個學系一棟，玩家住在自己學系的宿舍。
- **千頁圖書館**：島上最大的建築，大廳整理學習成果，上層是書庫，地下封著禁書庫。
- **學院商店**：賣衣服、帽子和家具的小店。

### 3.1 學院區域（＝遊戲的五個難度場景）

| 區域 | 樣子 | 對應學年 |
|---|---|---|
| 星芽花園 | 學院入口的花園，花瓣是數字的形狀，噴泉噴出的水珠會排成點數 | 一年級 |
| 千頁圖書館・上層書庫 | 書架高到看不見頂，書會自己飛回架上；階梯是一排排書脊（大廳是《萬題之書》和頁頁的家，沒有被污染） | 二年級 |
| 刻度鐘塔 | 全島的中心，巨大齒輪帶動整座島旋轉，鐘面上刻滿乘法表 | 三～四年級 |
| 分晶溫室 | 玻璃屋頂下種著會「分裂」的水晶植物，一顆果實可以切成幾等份 | 五～六年級 |
| 地下禁書庫 | 千頁圖書館的地下、島的最底層，有正數階梯往上、負數階梯往下，封印著《無解之書》 | 國中 |

## 4. 事件：無解之書

- 學院創校時寫了一對雙胞胎魔法書：
  - 《**萬題之書**》收錄所有被解開的題目，是學院的寶物。
  - 《**無解之書**》收留所有「還沒解完」的題目，等人來把它們算完。
- 幾百年來，太多學生算到一半就說「算了」，把題目丟進《無解之書》再也不回來。被放棄的題目越積越多，慢慢變成灰灰黑黑的**墨水**。
- 今年入學典禮那天，《無解之書》終於裝不下了。它爆開，墨水濺滿整個學院，變成一隻隻**墨水怪**。被墨水沾到的地方會褪成灰色，連數律都亂掉了：花開錯瓣數，鐘塔走錯時間。
- 爆炸時，《萬題之書》也被墨水濺到，書頁散落在學院各處，只剩**頁頁**這一頁還醒著。每當有人把一門數學魔法練到精通，那一章的書頁就會飛回書裡。
- 墨水怪身上都**掛著當年被放棄的那一題**。只要有人把那題算完，算式成立，墨水就會散開，變回乾淨的光點，被弄髒的地方也跟著恢復色彩。

> 為什麼是新生來救？因為老師們的魔力太強，一出手就把墨水連同題目一起炸碎，題目還是沒人算完，墨水很快又長回來。只有一題一題**親手算完**才有用，而新生算的正是這些基礎題。

## 5. 共鳴儀式與五個屬性

入學時，新生站上「**共鳴之井**」，井水會問他們幾個問題。問的不是會不會算，而是**「你喜歡怎麼想」**。答完後，井底的「**數晶**」會亮起一種顏色，那就是這個孩子的屬性，也是他之後的魔法系別。

> 遊戲裡這段就是**數學心理測驗**：進遊戲後由井水提問，沒有對錯，依答案決定屬性。詳細規則見企劃書第 4 節。

| 屬性 | 學系 | 思考方式（測驗判定） | 魔法樣子 | 學系能力（遊戲中） |
|---|---|---|---|---|
| 🔥 火 | 赤焰系 | **直覺速算型**：喜歡一眼看出答案、越快越過癮 | 火球、火柱、流星火雨 | 連擊加成更高 |
| 💧 水 | 蒼流系 | **變通型**：喜歡換個方法想，一條路不通就繞過去 | 水彈、漩渦、浪潮 | 每關有幾次「回流」：答錯可以收回重選 |
| ❄️ 冰 | 白霜系 | **精確步驟型**：一步一步來，算完會再檢查 | 冰錐、冰刺、暴風雪 | 「凍結時間」：限時變長 |
| 🌿 森 | 翠森系 | **圖像型**：喜歡畫圖、用東西排排看 | 藤蔓、花瓣、大樹 | 「萌芽提示」：叫出數線、積木或圖形輔助 |
| ⚡ 雷 | 紫雷系 | **推理找規律型**：喜歡猜規律、想為什麼 | 電球、連鎖閃電、雷擊 | 「消去」：劈掉一個錯誤選項 |

- 屬性沒有強弱之分，**每一種都是一種好的數學腦**。這是學院最重要的教導，台詞裡要常常提。
- 想換屬性的話，可以回共鳴之井重新測驗。設定上的說法是「人會成長，想法也會變」。

## 6. 角色

### 6.1 主角：見習魔數師（玩家）

- 主角**不取名**。遊戲裡一律稱呼玩家「**見習魔數師**」；對話裡用「你」，同學和老師叫「新生」，頁頁會親暱地叫「小魔數師」。
- 開始時選外觀：**女生**或**男生**。兩者的動作、能力、劇情完全一樣，台詞也一樣，所以台詞不能用「他／她」稱呼玩家。

| | 女生外觀 | 男生外觀 |
|---|---|---|
| 樣子 | 短披肩、圓圓的大魔數師帽、雙馬尾 | 斗篷、尖頂魔數師帽（帽尖總是歪的）、一撮翹髮 |
| 共同 | 魔杖頭有一顆數晶，顏色跟著屬性變；制服的滾邊顏色也跟著屬性變 | |

- 階級：見習魔數師 → 初級魔數師 → 中級魔數師 → 高級魔數師 → 大魔數師。在學院裡，魔數師的階級看的是**懂了多少數學**，不是年紀，也不是讀到幾年級，所以每個人都能一路升到大魔數師。升階要通過鐘塔的「升階考核」。稱號會跟著改，但平常還是叫「你」。

### 6.2 夥伴

- **頁頁**：《萬題之書》裡掉出來的一頁，變成一隻會飛的小書精靈。負責出題、在主角答錯時示範算法，也是遊戲裡的系統說明。話很多、愛吐槽，但從來不笑人算錯。口頭禪：「沒關係，我們一起算一次！」

### 6.3 學院的人

| 角色 | 身分 | 一句話 |
|---|---|---|
| 圓周院長 | 院長，又圓又矮的老魔數師 | 講話永遠講不完（「三點一四一五九……」），學生都要提醒他停 |
| 五位導師 | 每個學系一位，入學後才登場 | 個性跟該屬性的思考方式一樣，例如冰系導師講話一個字一個字慢慢講 |
| 管理員格格 | 千頁圖書館的貓頭鷹管理員 | 只說「安靜」跟「歸位」（第二階段再考慮要不要做） |

### 6.4 反派

- **墨水怪**：每隻身上掛著一道被放棄的題目，長相跟題目的區域有關，例如圖書館裡是書頁和塗鴉。它們不邪惡，比較像迷路、委屈的小東西。被打倒時不是死掉，而是「題目算完了，安心散開」。
- **墨水大王**：墨水最濃的地方聚成的大團塊，每個區域都有一隻，型態不同。它其實就是《無解之書》本身的情緒，一直在說：「反正沒有人會算完我。」

## 7. 故事大綱

1. **入學**：選外觀 → 入學典禮 → 共鳴儀式（心理測驗），決定屬性 → 《無解之書》爆開，學院被墨水淹沒。
2. **頁頁登場與第一場戰鬥**：頁頁找上你，說「只有新生親手算完才救得了大家」。話還沒說完，一隻墨水滴就從共鳴之井旁邊冒出來——它是爆炸後第一隻成形的墨水怪，身上掛著最簡單的加法題。頁頁在旁邊一步一步教你：怎麼選答案、算式怎麼變成魔法、連擊、你的學系能力、算錯了怎麼辦。這場戰鬥輸不了（算錯不會扣魔力），打完墨水滴散開，你第一次親眼看到「算完題目＝墨水消失」。
3. **五個區域**：從星芽花園到地下禁書庫。每清完一個區域，那裡就恢復色彩，那個學系的導師也會出現道謝。
4. **結局**：在禁書庫深處，墨水大王真身說出它的心聲。你把它最後一題、最老的那題算完，《無解之書》終於變乾淨，跟《萬題之書》合成一本。學院從此多了一條新規定：**算不完的題目可以先放著，但一定要有人回來算完。**這條規定也就是遊戲裡的「錯題本」。

> 難度可以隨時切換，劇情不會因此卡住：玩家選哪個學年，就從那個區域開始；清完五區才看得到結局。

## 8.5 成長：魔力從「懂」裡來

- 魔數師的魔力不是天生的，**每懂一條數學，魔力就多一點**。所以答對題目會讓你變強，練熟一門數學就學會一門新魔法。
- 魔杖上的數晶會記得你用它施了多少次魔法，用得越多越亮，魔法也越華麗。
- 頁頁會跟著《萬題之書》恢復而長大：從一張紙變成小冊子、精裝書，最後變成會發光的魔導書。
- 學院的「成長日記」是每位新生入學時拿到的空白本子，會自己寫下你每天練了什麼、進步了多少。
- 設定上的重點：**成長只來自練習和理解**，沒有捷徑，也不能用錢買魔力。商店只賣衣服、帽子這類外觀。

## 9. 題目情境：世界裡的數學魔法

每一道題目，都要寫成**這個世界裡真的會發生的事**，掛在墨水怪身上的就是「當年有人沒算完的那件事」。題目的數字、算法和答案都不能改，只換情境裡的人、事、物。

### 9.1 換詞原則

| 原本 | 換成（例） | 說明 |
|---|---|---|
| 人名、同學、工人、老師 | 學院的同學、學長姐、導師、魔像工人、精靈、居民 | 學院的人名沿用第 6 節；路人不取名，用身分稱呼 |
| 元、角、分 | **晶幣** | 金額數字不變 |
| 蘋果、糖果、鉛筆等東西 | 星果、魔晶糖、羽毛筆、魔藥瓶、咒文卷軸 | 數量相關的詞（個、支、瓶）照舊 |
| 汽車、火車、自行車 | 飛天掃帚、魔法馬車、浮空船、雲朵坐騎 | 速度、時間、距離照舊 |
| 工廠、商店、學校 | 魔藥工坊、學院商店、魔數學院 | |
| 修路、蓋房子 | 魔像修路、蓋學院塔樓 | |
| 公尺、公斤、公升、小時、度等單位 | **不換**，一律用台灣常用的公制單位 | 讓玩家學到的單位在現實裡也用得到 |

### 9.2 寫法

- **用台灣用語**：公斤（不用千克）、公尺（不用米）、公升（不用升）、立方公分、平方公尺。
- 題目要短：國小題目盡量在 60 個字以內，一年級盡量在 30 個字以內。
- 情境裡要**看得出是哪個區域**最好，例如星芽花園就用花、果實、蝴蝶，鐘塔就用齒輪、時鐘。看不出來也沒關係，不要硬塞。
- 純計算題（沒有情境的算式）不硬編故事，只加一句咒語開頭，例如「解開這道封印算式：」。
- 不寫打鬥、受傷、死亡；不寫考試、分數、被罵這類會讓人有壓力的情境。

### 9.3 範例

| 原題（意思） | 改寫 |
|---|---|
| 小明有 5 個蘋果，又買了 3 個，共有幾個？ | 花園裡的小精靈摘了 5 顆星果，又摘了 3 顆，一共有幾顆？ |
| 汽車每小時行 60 公里，3 小時行多少公里？ | 浮空船每小時飛 60 公里，3 小時能飛多少公里？ |
| 一件衣服 120 元，打八折後多少元？ | 學院商店的魔法斗篷原價 120 晶幣，打八折後要多少晶幣？ |
| 解方程式 3x＋2＝11 | 解開這道封印算式：3x＋2＝11，x 是多少？ |

## 10. 避免撞到的東西

- 不出現《轉生成星星碎片的我》裡的角色、地名和用語（星王、碎星鎮、零星等）。
- 不做成「分院帽」那種戴帽子分學院的橋段：決定屬性的是井水和數晶。學系名稱、校徽和制服也都自己設計，不參考現有作品。
