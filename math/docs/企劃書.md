## 1. 一句話

見習魔數師在被墨水淹沒的魔數學院裡，把墨水怪身上「被放棄的題目」一題一題算完：**答對就施展屬於自己屬性的魔法，讓學院恢復色彩。**

## 2. 目標與原則

| 項目 | 決定 |
|---|---|
| 對象 | 國小一年級～國中，學年可隨時切換 |
| 平台 | 網頁（手機直式為主，電腦也能玩） |
| 一局長度 | 3～5 分鐘（一關約 10 題，王關另計） |
| 學習重點 | **熟練度＋即時回饋**：答錯一定看得到正確算法，錯題本自動複習 |
| 不做 | 帳號、排行榜、內購、廣告；低年級不限時 |

設計原則：
1. **答題是唯一的操作**：不用一邊閃躲一邊答題，手機單手就能玩。
2. **算錯不可怕**：答錯只扣魔力，頁頁會示範算法。心理測驗沒有對錯，每種屬性都是「好的數學腦」。
3. **爽快感來自特效**：連擊越高，同一招會升級成更大的版本。

## 3. 遊戲流程與大地圖

### 3.1 畫面分兩種

| 畫面 | 視角 | 做什麼 |
|---|---|---|
| **大地圖** | 正交俯視（3/4 視角：看得到房子正面和屋頂，沒有透視） | 在學院浮空島上走動、和 NPC 說話、進出建築、碰到墨水怪 |
| **戰鬥** | 側視（現在的戰鬥畫面） | 答題施法 |

- **轉場動畫**（約 0.8 秒）：碰到墨水怪 → 畫面定格、墨水從怪物身上往外濺滿畫面 → 墨水裡浮出一圈發光的數字和符號旋轉收攏 → 拉開變成側視戰鬥畫面，玩家和怪物從兩側滑進定位。打贏時反過來：墨水散成光點，回到地圖原地，怪物不見。王戰的轉場多一段「封印環碎裂」，時間 1.2 秒。
- **操作**：左下角**虛擬搖桿**，同時也可以**點地圖上任一點走過去**（自動找路）；點 NPC、門、物件＝走過去並互動。電腦版用方向鍵／WASD，空白鍵或 Enter 互動。

### 3.2 大地圖：學院浮空島

| 地點 | 用途 |
|---|---|
| 浮空船碼頭 | 開場抵達的地方（教學：怎麼走路） |
| 中央廣場 | 共鳴之井（重測屬性）、圓周院長 |
| 學系宿舍 | 存檔、換外觀、佈置房間（玩家自己的學系） |
| 五個學系學院：赤焰塔、蒼流館、白霜堂、翠森苑、紫雷閣 | 各有一位導師：學系任務、分支魔法修練（練習場）、升階考核 |
| 千頁圖書館・大廳 | 《萬題之書》、錯題本、成長日記，頁頁的家 |
| 學院商店 | 用晶幣買帽子、斗篷、家具 |
| 受污染區域 ×5（＝五個學年） | 星芽花園（一年級）、圖書館上層書庫（二年級）、刻度鐘塔（三～四年級）、分晶溫室（五～六年級）、地下禁書庫（國中，在圖書館地下） |

- **明雷遇敵**：墨水怪在受污染區域裡看得到、會遊蕩，碰到才開打，沒有隨機遇敵。
- 每個受污染區域是一張小迷宮地圖：三群墨水怪（＝3 小關）→ 王房。打倒王後整張地圖從灰墨色恢復成彩色，擋路的墨水牆消失，捷徑打通。
- 五區不限順序。

### 3.3 完整流程

1. 標題 → 選外觀 → 搭浮空船抵達碼頭（教走路）→ 走到大廳參加入學典禮
2. 走到中央廣場的共鳴之井 → 共鳴儀式（第 4 節）→ 數晶亮起
3. 無解之書爆開，墨水淹沒學院 → 頁頁登場，帶你去千頁圖書館拿錯題本、成長日記（教成長）
4. 自由探索：進受污染區域（選學年）→ 三群墨水怪 → 王 → 恢復色彩 → 該學系導師道謝，開放學系任務
5. 回學院：修練、升階考核、商店、宿舍
6. 五區全清 → 地下禁書庫最深處的最終戰 → 結局（兩本書合一）→ 通關後繼續練習、收集
- **最終戰照玩家自己選的學年出題**，所以每個人都看得到結局。
- 第一次玩一定會跑完 1～3，可以跳過劇情對話，但不能跳過共鳴儀式。

## 4. 共鳴儀式（數學心理測驗）

### 4.1 規則

- 一共 **10 題情境題**，沒有對錯。場景是共鳴之井，井水用文字提問，頁頁會在旁邊說「照你真的會做的選就好」。
  - 8 題是**思考方式題**：每題 4～5 個選項，每個選項替 1～2 個屬性加分。
  - 2 題是**心情題**：測對數學的緊張程度，不影響屬性，用來調整遊戲的照顧程度（見 4.3）。
- 最高分的屬性就是結果，數晶亮出顏色並播放該屬性的施法動畫。
- **同分**時井水再補問一題，只列出同分的那幾個屬性。
- 結果畫面寫出「你是 ○○型」，用 2～3 句話說這種想法的優點，並說明學系能力。最後一定要提到「每一種都是好的數學腦」。
- 可以回共鳴之井重測。重測會換屬性，但收集品、星星和錯題本都保留。

> 注意：這是遊戲用的**趣味性向測驗**，不是正式的心理或學習診斷，遊戲裡和說明文件都不宣稱有診斷效果。題目自己寫，不抄現成量表。

### 4.2 題目草稿（之後再修文字，低年級版要有語音或更短的字）

| # | 情境 | 選項 → 屬性 |
|---|---|---|
| 1 | 老師說「8＋7 等於多少？」你腦中第一個出現的是？ | 直接冒出 15 → 火／先想 8＋2＝10，再加 5 → 水／一個一個數 → 冰／想像 8 顆糖和 7 顆糖 → 森／想到「跟 7＋8 一樣」→ 雷 |
| 2 | 遇到一題完全看不懂的題目，你會？ | 先猜一個答案再說 → 火／換個角度重讀 → 水／把題目一句一句拆開 → 冰／在紙上畫圖 → 森／找以前看過的類似題 → 雷 |
| 3 | 你最喜歡哪種謎題？ | 搶快的速算比賽 → 火／有很多種解法的謎題 → 水／數獨 → 冰／拼圖、七巧板 → 森／找規律的數字接龍 → 雷 |
| 4 | 寫完一張考卷，你通常會？ | 馬上交 → 火／換別的方法驗算一次 → 水／從頭到尾再檢查 → 冰／看看圖和單位對不對 → 森／檢查答案合不合理 → 雷 |
| 5 | 朋友算錯了來問你，你會怎麼教他？ | 直接說答案和最快的方法 → 火／告訴他另一種想法 → 水／帶他一步一步重算 → 冰／畫給他看 → 森／問他「你覺得為什麼會錯？」→ 雷 |
| 6 | 你覺得數學最好玩的是？ | 答對的那一瞬間 → 火／發現新方法 → 水／全部算對、很整齊 → 冰／圖形和形狀 → 森／想通「原來是這樣」→ 雷 |
| 7 | 要分 12 塊餅乾給 3 個人，你會？ | 一下就知道每人 4 塊 → 火／先每人 2 塊，剩下的再分 → 水／用除法算 12÷3 → 冰／把餅乾排成 3 排 → 森／想到 12 是 3 的 4 倍 → 雷 |
| 8 | 看到 2、4、8、16……你會想？ | 下一個 32！→ 火／也可能是別的規律？→ 水／檢查每一個是不是都乘 2 → 冰／想像越疊越高的積木 → 森／好奇它會不會一直下去 → 雷 |
| 9（心情）| 聽到「現在要考數學」，你的心情是？ | 好耶／還好／有點緊張／很緊張 |
| 10（心情）| 算錯一題的時候，你通常會？ | 沒差，再來／有點不甘心／有點難過／很想放棄 |

- 每個選項替對應屬性加 2 分。有些選項之後可以改成同時加兩個屬性各 1 分，讓結果不要太集中。上線前要用模擬測試，確認五種屬性出現的機率差不多，各 15～25%。

### 4.3 心情題的用途（不顯示分數）

| 緊張程度 | 調整 |
|---|---|
| 低 | 預設照學年規則（三年級以上有限時） |
| 中 | 頁頁答錯時的台詞更溫和；限時預設多 30% |
| 高 | 限時預設**關閉**；答錯後先鼓勵再講算法；魔力用完不顯示「失敗」，改成「休息一下」，自動降一小級 |

## 5. 屬性（＝魔法系別＋學系能力）

屬性**只**決定魔法外觀和學系能力，**不**決定題目難度。

| 屬性 | 學系 | 魔法（連擊等級 1→4） | 學系能力 |
|---|---|---|---|
| 🔥 火 | 赤焰系 | 火球 → 火柱 → 火焰龍捲 → 流星火雨 | 連擊分數加成 ×1.5 |
| 💧 水 | 蒼流系 | 水彈 → 水柱 → 漩渦 → 巨浪 | 「回流」：每關 2 次，答錯可以收回重選，不扣魔力 |
| ❄️ 冰 | 白霜系 | 冰錐 → 冰刺 → 冰霜新星 → 暴風雪 | 「凍結時間」：限時 ×1.5 |
| 🌿 森 | 翠森系 | 種子彈 → 藤鞭 → 花瓣風暴 → 大樹 | 「萌芽提示」：每關 3 次，叫出數線、積木、圖形輔助 |
| ⚡ 雷 | 紫雷系 | 電球 → 連鎖閃電 → 雷擊 → 雷暴 | 「消去」：每關 3 次，劈掉一個錯誤選項 |

能力的次數和倍率先暫定，M3 試玩後再調平衡。原則是任何一種屬性都不會明顯比較好過關。

### 6.4 題目情境改寫

- 下載的題目**全部**改寫成世界觀裡的情境，規則和範例見 [世界觀.md 第 9 節](世界觀.md)。數字、算法和答案都不能改，只換人、事、物；金額改成晶幣，單位一律用台灣的公制用語。
- 流程：
  1. `tools/` 的轉換腳本讀出原題，依數字大小和運算種類分到學年，產生「待改寫清單」。
  2. 依清單分批改寫，結果存在 `data/questions/rewrite/<來源>/*.json`，一題一筆，記原題 id、改寫後的題目和詳解。原題不改。
  3. 檢查腳本自動比對：改寫後題目裡的數字要跟原題一樣，答案要能從算式算回來，用語不能出現簡體字和中國用語（千克、米、升……）。
  4. 每批抽查 10%，有問題就修改寫表，再重跑一次。
  5. 合併成 `data/questions/built/<學年>.json` 給遊戲讀。
- 程式產生的計算題不用逐題改寫，在題目前面加一句符合區域的咒語開頭即可，例如「解開這道封印算式：」。

## 7. 核心玩法

### 7.1 畫面配置（手機直式 360×640 邏輯解析度，像素放大）

```
┌──────────────────────┐
│ ♥♥♥      連擊 x5   ★ │  ← 魔力、連擊、關卡進度
│   [背景視差 3 層]     │
│  玩家      墨水怪 ←   │  ← 戰鬥區（上 55%）
│  🧙        👾 7+5=?   │     題目掛在怪物頭上
│ ─────────────────────│
│ 頁頁：「先湊 10 試試」 │  ← 頁頁台詞（一行）＋學系能力按鈕
│ ┌────┐ ┌────┐        │
│ │ 12 │ │ 11 │        │  ← 四個答案按鈕（下 45%）
│ └────┘ └────┘        │     電腦可按 1～4
│ ┌────┐ ┌────┐        │
│ │ 13 │ │ 2  │        │
│ └────┘ └────┘        │
└──────────────────────┘
```

應用題字比較多時，題目改成顯示在中間的卷軸面板上，怪物會停下來等。

### 7.2 一題的流程

1. 墨水怪從右邊慢慢走來，頭上浮著題目。有限時的學年，怪物走到玩家面前就是時間到。
2. 答對：玩家寫下算式咒語，施展屬性魔法。墨水怪「安心散開」成光點，掉出靈感星，連擊＋1。
3. 答錯或時間到：墨水濺到玩家身上，扣 1 點魔力，連擊歸零。頁頁跳出**正確算法**（例如「7＋5：先湊 10，7＋3＝10，再加 2＝12」），停 2 秒或點一下繼續；應用題就顯示詳解。這題記進錯題本。

### 7.3 連擊與魔法升級

| 連擊 | 魔法等級 |
|---|---|
| 0～2 | 1 基本 |
| 3～5 | 2 強化 |
| 6～9 | 3 大魔法 |
| 10＋ | 4 終極（全螢幕） |

連擊只影響特效和分數，**不影響難度**。

### 7.4 魔力與失敗

- 每關 3 點魔力。用完就是「魔力耗盡」，可以選「再試一次」或「回學院」，**不扣任何進度**。
- 一、二年級，以及心情題「高緊張」的玩家：用完不算失敗，頁頁說「休息一下，我們換簡單一點的」，自動降一小級。

### 7.5 王關（墨水大王）

- 王有**墨水護盾**，一年級 3 格，國中 6 格。每格要答對一題才打得掉。
- 最後一格是「大招題」：從題庫裡挑一題應用題或選擇題，答對時放出終極魔法。
- 打倒後播「區域恢復色彩」動畫：場景從灰墨色漸漸變回彩色，那個學系的導師登場道謝。

### 7.6 錯題本

- 答錯的題目，連同當時的題型和數字，記進「錯題本」，也就是頁頁說的「還沒算完的題目」。
- 之後的關卡，錯題本裡的題型出現機率加倍。同題型連續答對 3 次就移出。
- 學院地圖可以進「錯題本特訓」：只出錯題本裡的題型。

### 7.7 評分與收集（成長另見第 8 節）

- 每關 1～3 顆星：答對率 ≥70% ★，≥90% ★★，全對 ★★★。
- **墨水圖鑑**：每種墨水怪、每個王、每一級魔法各一格。
- **帽子**：每拿滿一個區域的星星，解鎖一頂帽子（純外觀，男女生外觀共用）。

### 7.8 數學變魔法（答對時的演出）

答對後先演約 1 秒「算式化成魔法」，再放屬性招式。演出本身就是在示範算法。

| 題型 | 演出 |
|---|---|
| 加法 7＋5 | 杖頭冒出 7 顆和 5 顆光球，兩堆合在一起，每湊滿 10 顆融成一顆大光球 → 變成 12 發魔法 |
| 減法 12－5 | 12 顆光球裡 5 顆飛走熄滅，剩下 7 顆射出去 |
| 乘法 3×4 | 地上展開魔法陣，一列 4 個符文複製成 3 列，排成 3×4 方陣一起發動 |
| 除法 12÷3 | 12 顆光球平均分成 3 束，每束 4 顆 |
| 分數 | 一顆魔晶裂成幾等份，取其中幾份 |
| 小數、百分率 | 魔力條被 10、100 等分，亮起對應格數 |
| 正負數 | 往上（正）、往下（負）的光梯 |
| 方程式 | 封印鎖上浮著 x，算出的數字插進鎖孔 → 封印碎開 |
| 應用題 | 題目裡的關鍵數字從卷軸浮起、飛向杖頭，組成算式再發動 |

- 算式用發光的像素數字寫在空中，「＝」閃一下表示咒語成立；打中時答案數字像傷害數字一樣跳出來，連擊越高越大。
- 光球數量太多時（超過 20）改用「十顆一大球、百顆一大晶」表示，跟位值概念一致。
- 點一下可以跳過，跳過後只留數字變光球的短版。
- 答錯：寫到一半的算式「啪」地散成墨點，接著頁頁用同一套演出正確示範一次。

## 8. 成長系統

### 8.1 原則

1. **成長看努力和進步，不看年級**：經驗只看答對幾題、有沒有進步，跟題目屬於哪個學年無關。一年級和國中生升級的速度一樣。
2. **成長不能取代算數學**：等級再高，題目也不會自己變簡單，也沒有「自動答對」的能力。成長帶來的是：更多魔力、更多學系能力次數、更華麗的魔法、新玩法和外觀。
3. **看得見**：每一種成長都有數字，也有畫面上的變化（制服、魔杖、魔法、頁頁的樣子）。
4. **不懲罰**：不會掉級、不扣經驗；熟練度的星星只記「最好的一次」，複習交給錯題本。

### 8.2 六條成長線

| 成長線 | 怎麼長 | 長了有什麼 | 世界觀說法 |
|---|---|---|---|
| ① 魔數師等級 Lv1～30 | 答對題目、過關得經驗 | 魔力上限、學系能力次數、新玩法 | 懂的數學越多，魔力越強 |
| ② 階級（5 階） | 等級到了再通過「升階考核」 | 稱號、制服徽章與帽子、NPC 台詞 | 學院的正式資格 |
| ③ 魔法分支熟練度 | 每個數學主題各自算，看最近答題的正確率和速度 | ★3 學會該分支的特殊魔法；★5 恢復《萬題之書》一章 | 每一種數學都是一門魔法 |
| ④ 頁頁成長 | 《萬題之書》恢復的章數 | 頁頁變大、變厚，提示和功能變多 | 散落的書頁回到書裡 |
| ⑤ 數晶等級（每個屬性分開） | 用這個屬性答對的題數 | 屬性魔法的外觀進化 | 魔杖上的數晶越用越亮 |
| ⑥ 晶幣與外觀 | 過關拿晶幣 | 在學院商店買帽子、斗篷、魔杖外觀、宿舍家具（純外觀） | 這個世界的錢 |

### 8.3 ① 魔數師等級

經驗來源：

| 行為 | 經驗 |
|---|---|
| 答對 1 題 | ＋10 |
| 第一次答對某個題型 | ＋20 |
| 答對錯題本裡的題型 | ＋15（鼓勵複習） |
| 過關，每顆星 | ＋20 |
| 通過升階考核 | ＋100 |

連擊只加分數，**不加經驗**，避免玩家為了經驗緊張搶快。

- 從 Lv n 升到 Lv n＋1 要 100＋20×（n－1）點經驗，升到 Lv30 一共約 11,000 點。一關大約 150 點，玩 70 關左右，約 5 小時。
- 升級獎勵：

| 等級 | 獎勵 |
|---|---|
| Lv3 | 魔力上限 3 → 4 |
| Lv5 | 學系能力每關次數＋1 |
| Lv8 | 開放「練習場」：自己選題型、不限時練習 |
| Lv10 | 魔力上限 4 → 5（上限就是 5） |
| Lv12 | 學系能力每關次數＋1 |
| Lv15 | 開放「挑戰模式」：限時連答，看能連對幾題 |
| Lv20 | 開放**副屬性**：可以再裝一個其他屬性的學系能力（次數減半） |
| Lv25 | 學系能力每關次數＋1 |
| Lv30 | 「大魔數師」稱號資格、金色長袍外觀 |

沒列出來的等級，每升一級給 20 晶幣。

### 8.4 ② 階級與升階考核

| 階級 | 需要等級 | 外觀變化 |
|---|---|---|
| 見習魔數師 | 一開始 | 沒有徽章 |
| 初級魔數師 | Lv6 | 銅徽章 |
| 中級魔數師 | Lv12 | 銀徽章、帽子加一圈滾邊 |
| 高級魔數師 | Lv20 | 金徽章、披風 |
| 大魔數師 | Lv30 | 星形徽章、金色長袍 |

- 等級到了，學院地圖上的鐘塔會亮起「升階考核」。考核是 10 題，從玩家自己選的學年、已經學過的題型裡出，答對 7 題就通過。不限時，沒通過也沒有懲罰，隨時可以再考。
- 階級只看等級和考核，**跟清完哪個區域無關**。所以只玩一年級區域的玩家，也能一路升到大魔數師。

### 8.5 ③ 魔法分支熟練度

每個題型都歸到一個魔法分支：

| 分支 | 數學內容 | 主要學年 |
|---|---|---|
| 增減術 | 加法、減法、補數 | 一～二年級 |
| 倍分術 | 乘法、除法 | 三～四年級 |
| 時律術 | 時間、速度、距離 | 二～六年級 |
| 形陣術 | 圖形、周長、面積、體積 | 三～六年級 |
| 分晶術 | 分數 | 三～六年級 |
| 點晶術 | 小數 | 四～六年級 |
| 比率術 | 百分率、比、比例 | 五年級～國中 |
| 正負術 | 正負數 | 國中 |
| 解謎術 | 未知數、方程式 | 六年級～國中 |
| 數列術 | 規律、數列 | 國中 |

- 星星看這個分支**最近 20 題**的表現：正確率 ≥60% ★1、≥70% ★2、≥80% ★3、≥90% ★4；≥90% 而且平均作答時間在目標時間內 ★5。題數不到 20 時，用已有的題數算，但最少要答 5 題才開始給星；不到 10 題最多 ★2、不到 20 題最多 ★4，★5 精通一定要滿 20 題。
- 星星只記最好的一次，不會往下掉。
- **★3：學會分支魔法**。這是戰鬥中可以用的特殊技，每關一次，效果小、不會幫你答題，例如：
  - 增減術「回復」：魔力＋1
  - 倍分術「分身」：下一題答對可以打倒兩隻墨水怪
  - 時律術「慢流」：這一題的怪物走得慢一半
  - 形陣術「護陣」：下一次答錯不扣魔力
  - 其他分支各一招，做到再設計
- **★5：精通**。《萬題之書》恢復一章，那一章會寫上這門魔法的重點整理，也就是給玩家看的公式和觀念小卡。

### 8.6 ④ 頁頁成長

| 恢復的章數 | 頁頁的樣子 | 新功能 |
|---|---|---|
| 0 | 一張紙 | — |
| 1 | 小冊子 | 答錯時可以「分步驟看」算法 |
| 3 | 精裝書 | 錯題本特訓會出「相似題」：數字不同、算法相同 |
| 6 | 魔導書，會發光 | 每天一題「頁頁的謎題」（加分題，答錯不扣魔力） |

一年級玩家能精通的分支比較少，所以門檻刻意設低（1、3、6 章）。

### 8.7 ⑤ 數晶等級

- 每個屬性分開記：用這個屬性答對 1 題得 1 點。等級門檻 Lv1 0、Lv2 50、Lv3 150、Lv4 300、Lv5 500 點。
- 每升一級，這個屬性的四級魔法**外觀進化**：更大、更亮、多一層粒子。Lv5 時終極魔法換成第二型態。
- 外觀進化用 pixelfx 的參數做（大小、粒子數、亮度、多一層光暈），不用每一級重畫一套，控制美術量。
- 回共鳴之井換屬性時，舊屬性的數晶等級會保留。

### 8.8 ⑥ 晶幣與外觀

- 每關 10～30 晶幣，看星星數；升級、升階、精通分支另外給。
- 學院商店賣帽子、斗篷、魔杖外觀、宿舍家具，**全部純外觀**，不賣任何能力。
- 宿舍房間（M5 之後）：可以擺家具，也放已經解鎖的獎盃、《萬題之書》和頁頁。

### 8.9 成長日記（給玩家和家長看）

- 學院地圖上的「成長日記」記錄：每天答了幾題、正確率、各分支星星的變化。
- 用折線圖顯示「最近 7 天」和「最近 30 天」，讓進步看得見。
- 只存在這台裝置的瀏覽器裡，不上傳。

## 10. 美術製作方式

照現有美術規則：外框只用黑，內線不用黑；色數依類別算，角色 16、雜兵 12、王 24、特效 8、介面 12、場景整關 24；真像素、剪影清楚、風格一致、動畫不滑步。每樣素材做之前**先找多個參考**。

| 素材 | 做法 |
|---|---|
| 見習魔數師（男女）、頁頁、墨水怪、王、NPC | **pixelfx** 程式畫，用 critters 的形狀加受光分階畫法，畫→看→修三輪 |
| 施法特效 | **pixelfx** 現成特效改色、改大小。火（fireball、flame-pillar、fire-tornado、meteor）、冰（ice-lance、ice-spikes、frost-nova、blizzard-vortex）、雷（ball-lightning、chain-lightning、lightning-strike）可以直接改；水、森沒有完整的現成組，用現有特效改寫補上 |
| 寫咒語、墨水散開、拾取靈感星 | pixelfx（arcane 的 magic-circle-cast、rune-circle；death／pickup 類改成墨水色） |
| 5 個區域背景（各 3 層視差＋地面），加共鳴之井、學院地圖 | **AI 參考圖 → pixel-redraw** 照格子讀回、控色、修外輪廓，給使用者看過才接進遊戲。提示詞記在 `math/docs/美術提示詞.md` |
| 「褪色→恢復色彩」 | 同一張圖在遊戲裡即時去飽和、混墨色，不另外畫灰色版 |
| 介面 | 自己畫像素 UI。按鈕顏色照規則：金＝主要，紅＝危險，紫灰＝一般 |
| 字型 | 題目用自製像素數字字型（0～9、＋－×÷＝□、分數線、負號）；中文用授權可商用的像素中文字型 |
| 音效、音樂 | **sfx-select** 挑選：五個屬性的施法聲、答對、答錯、連擊升級、王登場、恢復色彩。音樂 4 首：標題、學院地圖、關卡、王 |
