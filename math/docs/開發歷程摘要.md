# 《魔數學院》開發歷程摘要

整理日期：2026-11-26。內容來自我們的對話、git 紀錄（math/ 共 78 個 commit，2026-11-25～26），以及世界觀、企劃書。

---

## 一、這是什麼遊戲

- **定位**：國小中年級的數學學習 RPG。題目算對就變成魔法，打倒墨水怪，讓學院恢復色彩。主題是「數學是一種魔法」。
- **玩家**：見習魔數師，只選男生或女生的外觀，不取名。入學測驗（共鳴儀式）決定屬性：火、水、冰、森、雷。
- **題目**：聚焦中年級的十個單元：大數加減、乘法、除法、四則併式、分數、小數、面積周長角度、時間與單位換算、概數與估算、數量規律。題庫原檔是 TMMLU+ 和 Calc-ape210k（都是 MIT 授權），抽查後補過題目。
- **畫面**：橫版 16:9，點選操作，沒有大地圖。
  - 背景和建築用 AI 原圖照像素格讀回。
  - 角色、怪物、特效是程式畫的像素圖（pixelfx）。
- **網址**：
  - 雲端版（有登入、雲端存檔、教師後台）：https://mosu-academy.y8999y.workers.dev/
  - 靜態版（只存在本機）：https://y8999y-ops.github.io/zero-star-hero/math/
  - 離線版：`math/offline/魔數學院-離線版.html`，點兩下直接玩。

## 二、做了哪些事（依時間）

### 1. 起步：世界觀與企劃（11-25）
- 改名《魔數學院》。先寫世界觀：數律之地、無解之書、共鳴儀式五屬性。
- 企劃書從 v0.4 寫到 v0.9：成長系統（Lv1～30、五階、升階考核）、十門魔法分支、圖書館、設施與玩法。

### 2. 原型與 10 批製作（11-25）
- **M1 原型**：從標題開始，選外觀、入學劇情、共鳴儀式、學院地圖、戰鬥，可以完整玩一輪。
- **M2**：主角像素圖、加減乘除和其他題型的「數學變魔法」演出、戰鬥轉場、設定選單。
- 原本 28 批合併成 **10 批**。每批做到能玩的一段進度，再一起給你看：
  1. 星芽花園戰鬥背景
  2. 墨水滴與頁頁
  3. 歪瓣花與墨水大王・幼體
  4. 大地圖、NPC、第一批音效
  5. 開場動畫、入學典禮、圖書館、星芽花園區域
  6. 導師與學系小遊戲、同學每日問題、布告欄委託、商店、宿舍、溫室、共鳴之井
  7～8. 其他區域的戰鬥背景（分晶溫室、地下禁書庫）與新墨水怪
  9. 最終戰、結局、分支魔法、副屬性
  10. 程式合成的背景音樂 7 首，還有字型與文件
- 學院島地圖改了很多版（v2 到 v5b，同心圓、三層台地、曲線崖邊）。最後**決定拿掉大地圖**，改成橫版點選：學院全景左右滑，點建築、人、寶箱。

### 3. 介面與手機（11-25）
- 第一次點畫面就自動全螢幕並鎖橫向，也可以加到主畫面。畫面填滿手機和平板。
- 程式畫的像素按鈕和外框。字型最後改成一般黑體，比較好讀。
- 所有劇情改成動畫演出，共用一個劇情播放器。

### 4. 戰鬥系統打磨（11-25～26）
- 題目決定招式：十個單元各有一招，用屬性色；連擊高還會疊上屬性大招。
- 怪物有個性，例如散頁怪答錯會回血。
- **完美詠唱**：答得快，魔法升一級。
- 王會分階段變身。
- **限時**：
  - 四上、四下 28 秒，總複習 32 秒，挑戰模式 20 秒。
  - 熟練度還是用原本的秒數算。
- 結算畫面精簡成一張卡。
- 五座學院改成課程訓練。每個單元的簡單和困難**合併成一關**，題目由易到難；長度選「基礎／進階／精熟」（3／5／10 題）。
- **11-26 這一輪調整**：
  - 戰鬥愛心放大，失去的那顆有動畫。
  - 怪物血量改成**數值**，每隻打 2～3 下。血條沒有數字，扣血時會抖動、閃白，有一段落後的殘影，血少時閃橘色。
  - 錯題講解不在戰鬥中跳出來，改成結算時按「錯題講解」看，每題下面有「去學一學」。
  - **技能鈕刪掉**，分支魔法和數晶大招都自動施放：
    - 治療：剩 1 顆心時。
    - 護盾：答錯後。
    - 分身：連對 3 題。
    - 重試：選錯時。
    - 刪去：8 秒還沒答。
    - 提示：12 秒還沒答。
    - 緩速：限時題過一半時。
  - 每個技能都有專屬跳字特效。大招重做：先集氣，五種屬性各有一套連發，最後光爆。
  - 普通攻擊的打擊感加強：停頓、擊退、壓扁拉長、閃白。怪物會照被打的屬性反應，例如著火、結冰、觸電。
  - 命中跳字改成**多段數字**：魔法第 1～4 級 2～5 段，分身多 2 段，組合技 6 段，大招 8 段。血條也一段一段掉。
  - 結算按鈕改成「**完成**」和「**下一關**」。沒過關時第二顆變成「再挑戰」。

### 5. 雲端版與部署（11-26）
- 雲端版（Cloudflare Workers + D1 資料庫）：
  - 學生用代碼登入，存檔放雲端，換裝置也接得上。
  - 會記錄遊玩時間和錯題。
  - 教師後台：全班總覽、弱點分析、班級與學生管理、QR Code 登入小卡、下載總表與錯題（Excel 能開）。
- **自動部署**：推上 GitHub 之後，Cloudflare 會自己打包、更新資料表、部署（Workers Builds）。
  - 部署時資料表會自動建立，不會清掉資料。
  - 教師密碼是 Cloudflare 的 Secret：`ADMIN_PASSWORD`，在 Settings 的 Variables and secrets，不是 Builds 底下那一區。
- **登入整合**：
  - 標題頁右上角只有一顆「登入」，分「學生」和「老師」兩個分頁。
  - 老師用密碼登入後可以開後台、試玩，試玩不會記錄。
  - 老師和學生不會同時登入。
- **學生代碼**：改成 **4 位數字**（0000～9999，可以有 0）。舊代碼照樣能用。後台可以一鍵把全班換成 4 位數。下載的檔案會保留代碼開頭的 0。
- **離線版**：整個遊戲塞進一個 html（約 17 MB），不用網路也不用伺服器。

## 三、我們定下的工作規則

- 用繁體中文、短句說明。你常用手機或平板看。
- **企劃由我決定**，寫進文件，不再逐項問你。設定改動先寫世界觀（docs/世界觀.md），再寫企劃書（docs/企劃書.md）。
- **改完測過就自動 commit 並推上**，不用問。只推 `math/`，其他資料夾（unity/、art/）的檔案不碰。
- 測試用手機尺寸 844×390、開靜音，測完關掉分頁。
- 美術流程：
  - 做素材前先找多個參考。
  - AI 原圖照它自己的像素格讀回，不重畫。
  - 外框只用黑色，內線不用黑。
  - 色數依類別各自計算。
- 特效照 pixelfx skill：先找範例，畫、看、修至少三輪。
- 按鈕顏色：金色＝主要，紅色＝危險，紫灰＝一般。
- 下載檔案前先問你。
