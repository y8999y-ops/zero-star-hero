# 題目情境改寫表

每個檔案是一批改寫結果（JSON 陣列），一題一筆。原題在 `../work/<來源>.json`，由 `npm run extract` 產生；改寫規則見 `../../../docs/世界觀.md` 第 9 節。

改完要跑 `npm run check` 檢查。

## 欄位

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | ✔ | 原題 id |
| `keep` | ✔ | `false` 表示不收這題，要寫 `why` |
| `why` | 不收時 | 不收的原因，例如題目缺資訊、答案對不上、奧數題不在課綱 |
| `grade` | 收時 | 重新判斷的學年：`g1` 一年級、`g2` 二年級、`g34` 三～四年級、`g56` 五～六年級、`jh` 國中 |
| `text` | 收時 | 改寫後的題目 |
| `answer` | 收時 | 應用題：數字，要跟原題答案一樣（`unit` 是 `%` 時是原答案 ×100）。選擇題：`A`～`D` |
| `unit` | 應用題 | 答案的單位，例如「顆」「公尺」「晶幣」 |
| `choices` | 選擇題 | 四個選項（可以修格式，不能改意思） |
| `explain` | 收時 | 給玩家看的簡短算法 |
| `numsNote` | 視情況 | 題目裡的數字跟原題不同時要寫原因（例如換單位、修正壞掉的次方），檢查才會放行 |
