# 讀 bilibili 教學影片（字幕燒在畫面上、沒有字幕檔）

2026-11-17 讀 Mushreb DEV LOG.01～05 用的方法。不用登入：未登入只有 360p，但字幕讀得出來。

1. 用內建瀏覽器打開影片頁（`mcp__Claude_Browser__navigate`）。網址會轉到 zh-Hant，第一次跑的腳本可能被打斷，重跑一次就好。
2. 先查資訊和字幕檔：在頁面上執行
   `fetch('https://api.bilibili.com/x/web-interface/view?bvid=<BV號>')` 取得標題、說明、長度、cid。
   `fetch('https://api.bilibili.com/x/player/wbi/v2?bvid=<BV號>&cid=<cid>')` 的 `data.subtitle.subtitles` 是空的，就表示沒有字幕檔。
3. 字幕條掃描：影片靜音、暫停，每 1 秒跳一次（要等 `!v.seeking && v.readyState >= 3` 再多等 120 ms，否則畫到黑畫面）。每次把畫面高度 76%～94% 那一條畫到 canvas。
   - 去掉重複：只看「很白、而且旁邊 2 格有很暗的像素」的點（白字黑邊），跟上一條比交集／聯集，大於 0.4 就跳過。雪、雨這種白點很多的畫面也不會誤判。
   - 把留下的字幕條疊成一張（一張 9 條，第 10 條會被切掉），蓋在頁面最上層，再截圖讀。
4. 截圖常常是上一次的畫面：畫完先 `wait` 0.5 秒再截。
5. 關鍵畫面：同一個方法跳到幾個時間點，2×2 或 2×3 拼成一張看效果長怎樣。
6. 一次執行最多約 45 秒。掃描放在背景跑（不要 await），再用另一次執行等 `scanDone`。
7. 讀完關掉分頁。
