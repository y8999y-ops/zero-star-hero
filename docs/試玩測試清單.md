# 第一章試玩版：真機測試清單（2026-11-05）

我在電腦的瀏覽器裡測不到的東西：真的手機上的效能、手感、聲音、畫面看起來的樣子。
請在手機上從頭玩一輪，遇到問題時記下「在哪一關、剛做了什麼、看到什麼」，截圖最好。

## 怎麼開始
- 想從頭體驗新玩家的流程：手機瀏覽器開遊戲網址，用無痕模式（不會讀到舊存檔），從標題畫面開始。
- 想接著玩：直接開，會讀到原本的存檔。

## 一、效能與畫面
- [ ] 遊戲跑起來順不順？打一大群怪、放大招的時候會不會卡頓？
- [ ] 手機會不會很燙、很耗電？（玩 15 分鐘看看）
- [ ] 鏡頭拉近 20% 之後：角色、怪的大小好不好？會不會覺得看得太近、怪從畫面外衝進來來不及反應？
- [ ] 背景、地形、平台有沒有怪怪的地方（破圖、閃爍、顏色奇怪）？
- [ ] 1-4 巢穴的黏液、王房牆上的抓痕看得出來嗎？
- [ ] 夜晚、地圖頂端的尖刺：在地圖底部看不到、爬到上面才看到，這樣對嗎？

## 二、手感
- [ ] 搖桿、跳、二段跳、閃避好不好按？
- [ ] 平台跳躍：郊狼時間（走出邊緣還能跳）夠不夠？有沒有哪裡老是跳不上去？
- [ ] 攻擊、技能、大招的打擊感夠不夠？
- [ ] 四個形態的大招各放一次：看起來、用起來有沒有差別？哪一招太強或太弱？
- [ ] 魔力：會不會常常不夠用、或一直用不完？

## 三、聲音（我都是靜音測的，完全沒聽過）
- [ ] 音樂、音效大小合不合適？
- [ ] 新加的聲音：怪物發現你的「叮」、低血量心跳、拿到星之殘火的音效、死亡碎掉
- [ ] 有沒有哪個聲音太吵、太刺耳？

## 四、流程（我已經用新存檔自動跑過一遍，但沒有真的「玩」過）
- [ ] 開場動畫 → 1-1 → 回碎星鎮 → 公會登記、接任務 → 1-2 → 1-3 → 1-4 打王 → 回碎星鎮
- [ ] 打完王回城鎮之後，四處走動、去公會／工坊／旅館，**方向鍵（搖桿）還能不能動？**
  - 如果又卡住：記下卡住前最後做了什麼（跟誰說話、開了什麼視窗、按了什麼）
- [ ] 死掉：碎掉 → 祭壇重生的演出順不順？會不會卡住？
- [ ] 王戰中死掉：重打時王是滿血、屋頂破洞會重新塞住嗎？
- [ ] 有沒有哪裡迷路、不知道要去哪？
- [ ] 第一章大概玩了多久？
