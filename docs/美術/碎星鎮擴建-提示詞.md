# 碎星鎮擴建 AI 提示詞（2026-11-19 第二版）

生圖 → 存進 `art/1-參考原圖/town2/` → 照 `.claude/skills/pixel-redraw` 讀回、壓色、套外框規則 → 給使用者看 → 通過才接進遊戲。

**第二版改了什麼**：
- 第一版要 AI 畫「沒有像素的平塗插畫」，改回我們做過、已經通過的寫法：叫 AI 畫 16-bit 像素圖，我再照它自己的格子讀回。
- 色調改回已通過的碎星鎮（深靛紫陰影、金和青點綴）。白天、晚上由遊戲的光照處理，素材不用畫成白天。
- 每張都附一張**尺規圖**，讓 AI 畫的像素大小一致。
- 天空不用產：用現在的天空，往上延伸的部分用程式補漸層。

## 擴建的方向（我定的，玩法細節之後寫進企劃書）

- **慢慢蓋出來**：一開始跟現在一樣只有一條街。中層鎮長家接「建設委託」（用撿回來的垃圾和金幣），蓋好一區才開一區。
- **可以往上爬**：用樓梯、繩梯、屋頂、平台上下層。每層放一個路標，可以直接傳到別層（手機上不用一直爬）。
- **整個城鎮** 2400×560 格（現在 1240×216），畫面一樣是 216 高。

```
y≈120  上層 ┃        鐘樓頂            墜星殘骸觀星台            大樹樹冠        ┃
y≈290  中層 ┃   城牆步道   住宅屋頂 ～吊橋～ 石台地（鎮長家）  樹屋 ～繩梯～   ┃
y≈450  地面 ┃ 城門  公會   住宅   中央廣場（噴水池）  工坊   住宅   旅館   大樹根 ┃
y≈560  地下 ┃            ═══ 舊下水道（祕密區域，從廣場旁的人孔下去）═══         ┃
            x=0                                                          x=2400
```

## 共用規格

- **尺規圖**（都在 `art/1-參考原圖/town2/`）：洋紅底，左下角是已通過的木桶，放大成「一格遊戲像素＝6×6 或 4×4 個方塊」。
  - 生圖時上傳該張指定的尺規圖，貼上提示詞，輸出尺寸照下表選。
  - 木桶留在圖裡沒關係，讀回時拿它對大小（木桶讀回應該是 38×40）。
  - 為什麼有 6 和 4 兩種：鐘樓、大樹、城門、住宅太大，用 6 的話放不進 1536×1024。
- **往上延伸的遠景、中景**：上傳 `extend-far.png`、`extend-mid.png`（已通過的圖放大 3 倍貼在下面），請 AI 把上面的洋紅畫滿。
- **底色**：洋紅。這批沒有大面積的紫和粉紅；如果某張被挖掉，就改成綠底重產。
- **色數**（照每物件上限）：建築 21、小物件 16、場景層整個城鎮共用 24。
- **不滿意就重生**：數量不對、物件疊在一起、跑出文字或人物，就重生一次。
- 提示詞用英文：生圖模型對格式要求聽得比較懂。

## 每張都先貼這段（共用風格）

```
Asset for a 2D side-scrolling 16-bit pixel art game. Crisp hard-edged square pixel clusters, limited palette about 24 colors, no anti-aliasing, no blur, no gradients inside shapes, flat cel shading in 3-4 steps, upper-left lighting, cozy whimsical dark fantasy, deep indigo/violet shadows with gold and cyan solid accents. Strict orthographic side/front elevation. NO bloom, NO halo, NO glow outside objects, NO light beams, NO rays, NO particles, NO fog, NO soft light spill. Bright crystals and windows must be flat hard-edged colored shapes contained within their silhouettes. Lighting VFX will be added by code. No text, lettering, watermark, UI, characters, people, animals, perspective or isometric. CRITICAL BACKGROUND RULE: use a perfectly uniform solid #FF00FF magenta background, no vignette, no dark backdrop, no shadow on the ground; object edges meet the magenta directly with zero halo.
```

用尺規圖的那幾張，再接這段（`<N>` 換成表裡的 6 或 4）：

```
The uploaded image is the scale and style reference. The wooden barrel in the bottom-left corner shows the exact pixel size: every game pixel is one solid <N>x<N> square block. Keep the barrel exactly where it is, unchanged. Draw the new art at exactly the same pixel size and in the same style, never overlapping the barrel.
```
