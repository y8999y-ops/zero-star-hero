# 零星勇者 場景美術 AI 提示詞

用 AI 產生場景素材（背景、中景、前景、建築、草和小物件）。
主角、NPC 和怪物**不在這份清單裡**，它們照 `終極版規則v2.txt` 由程式繪製。

---

## 0. 使用方式

1. 先複製「共用風格」，再接上該張圖自己的提示詞，一起貼給 AI。負面提示詞要分開貼。
2. 生成的圖照表格裡的**檔名**存到指定的**資料夾**。
3. 不用自己縮圖，AI 給多大就存多大。我之後會統一縮成遊戲用的像素大小、對齊色盤，再接進遊戲。
4. 同一個場景請盡量用同一個 AI、同一種設定一次產完，風格才會一致。可以的話固定 seed，或者把第一張滿意的圖當成「風格參考圖」再產其他張。

### 遊戲畫面的規格（給你參考，提示詞裡已經寫好了）
- 畫面高 216 像素，寬 320～480 像素。地面在 y = 184 的位置，大約是畫面由上往下 85% 的地方。
- 主角大約 24 像素高，**只有畫面高度的 1/9**。所以背景的東西要畫得很大、很遠，才有份量。
- 光從左上照下來。整體偏暗，靠水晶、星星碎片和窗戶的光照亮。

### 去背規則（重要）
除了「天空」以外，每一張都要**純洋紅色 #FF00FF 的平塗背景**，我會用程式把洋紅色挖掉。
- 背景不能有漸層、陰影、地平線，也不能有雜點。
- 畫面主體裡不要出現洋紅色或很接近的粉紫色。
- 如果你的 AI 能直接輸出透明背景的 PNG，用透明背景更好。

### 無縫接續
背景層（遠景、中景、前景草叢）在遊戲裡會一直左右重複，所以要能**左右無縫接續**：圖的最左邊和最右邊要能接起來。
- 如果 AI 有「seamless / tileable」的選項，請打開。
- 如果沒有也沒關係，接縫我來修。

## 2. 世界觀重點（寫提示詞的依據）

- **碎星鎮**：建在隕石坑內側的台地上，四處都是墜落的星星碎片。居民是史萊姆、石頭魔像、蘑菇這類魔物。
  - 冒險者公會：石塊牆、木柱、瓦片屋頂。大廳是繞著第一塊墜落的碎片蓋起來的，碎片從屋頂穿出去。
  - 工坊：魔像用巨石鑿出來的圓頂石屋，有疊石煙囪和爐火。
  - 旅館：一朵巨大的紅蘑菇，柄是牆、蓋子是屋頂。
- **墜星之谷**：主角掉下來的魔物洞窟。昏暗的岩洞裡長著苔蘚和青色水晶，上面的世界丟下來的垃圾（輪胎、鐵罐、木板、生鏽的鐵）堆成了垃圾山。
- 色調：深藍紫色的暗部，搭配金色的星光和青色的水晶光，可愛而不恐怖。

## 5. 場景小物件　資料夾 `game/art/props/`

- 每個物件之間要**留大片洋紅色的空隙，不能互相碰到**。

## 6. 檢查清單（存檔前看一眼）

- [ ] 背景是純洋紅色（天空和墜星之谷的 back.png 除外）。
- [ ] 畫面裡沒有文字、浮水印，也沒有人物或動物。
- [ ] 是側面平視的角度，不是俯視或斜角。
- [ ] 像素邊緣是硬的，沒有糊掉。輕微的雜點我可以清掉。
- [ ] 檔名和資料夾都跟表格一樣。

產好就跟我說「素材好了」。我會檢查、縮成遊戲尺寸、統一色盤後接進遊戲，再截圖給你看效果。
