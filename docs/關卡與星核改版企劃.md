# 關卡與星核改版企劃 v0.1（2026-11-05）

> 標記：✅ 已定案　📝 草案（我先定的，可以改）

## 1. 已定案 ✅

- 星核走 **B 會掉落**：每顆星核有固定的「核心效果」，換一顆就換一種玩法。
- 星核**不參與套裝**，套裝只看另外 6 件（冠、殼、爪、靴、碎片×2）。
- 星核**滿級是別人的兩倍**：一般 +5／10／15／20／25／25 → 星核 +10／20／30／40／50／50。
- 關卡參考 **Ori**：拿掉隱形牆和一波一波的遭遇戰，怪物直接擺在地圖上；地圖往上下延伸；怪物多一點。
- 怪物重生：**規則 2**，重進關卡才重生。
- **形態開路**：要。
- 一次性資源：要，名稱和外觀照世界觀調整（見第 4 章）。
- **地圖**：要。
- 死掉後從**祭壇**重來。

## 2. 星核 📝

### 2.1 規則
- 每 10 級加一次副屬性（一般裝備是每 5 級），總次數一樣是 5 次。
- 多出來的等級長主屬性（攻擊力）和核心效果：+0、+10、+20、+30、+40、+50 各一階，共 6 階。
- 稀有度越高，核心效果的數字越大（同一種效果，傳說比普通強）。
- +25 以後的成功率接著往下：+25～+29 20%、+30～+39 15%、+40～+50 10%。失敗不會掉級（跟現在一樣）。
- 史詩不會再掉「套裝星核」，改掉「史詩星核」（只是數字比較大的核心效果）。

### 2.2 十種星核的核心效果（數字是第 1 階 → 第 6 階）
| 星核 | 核心效果 |
|---|---|
| 鏽色星核 | 連段最後一下傷害 +20% → +60% |
| 晨光星核 | 生命 80% 以上時傷害 +8% → +24% |
| 沉重星核 | 普攻擊退 +20% → +60%，被打飛的敵人撞到別的敵人時也會受傷 |
| 隕鐵星核 | 每 12 → 7 秒，下一次技能多叫一顆小隕石 |
| 尖銳星核 | 暴擊時多打一次 10% → 30% 的星光傷害 |
| 暗影星核 | 閃避後 2 秒內傷害 +10% → +30% |
| 細長星核 | 普攻距離 +10% → +30% |
| 彗尾星核 | 衝刺留下一道星光尾巴，敵人碰到受傷（20% → 60% 攻擊力） |
| 鈍光星核 | 被打時 8% → 20% 機率讓攻擊的敵人暈 1 秒 |
| 巨岩星核 | 生命低於 40% 時防禦 +20% → +60% |
| 很吵的星核（傳說） | 原本的效果不變，等級越高增益時間越長 |

## 3. 關卡（參考 Ori）📝

### 3.1 地圖
- 每一關是一張大地圖，大約橫 6～8 個畫面、直 3～4 個畫面；鏡頭左右上下跟著主角。
- 分成幾個「區域」：主路線一條，旁邊有支線洞穴、上層平台、地下水道之類的地方可以探索。
- 地形有牆、天花板、豎井、斜坡（之後再看要不要）、會掉下去的平台（現有的單向平台）。
- 王的房間是真的牆圍起來的，不是隱形牆。

### 3.2 怪物
- 每關 40～60 隻，分散擺在各區，有單隻也有 3～5 隻一群；菁英擺在比較難走的地方或寶物前面。
- 打死不會重生，重進關卡才重生（規則 2），想刷就重進。
- 在祭壇復活時，已經打死的怪不會回來。

### 3.3 形態開路（像 Ori 的能力開路）
| 機關 | 要用的形態 | 世界觀 |
|---|---|---|
| 裂開的垃圾牆 | 鐵罐星衝撞撞破 | 上面的世界丟下來堆成牆的垃圾 |
| 大坑、深淵上的風 | 蝠翼星滑翔飛過去 | 深淵往上吹的氣流 |
| 黏液菇（彈跳墊） | 黏液星踩上去彈很高 | 黏液滲進土裡長出來的菇 |
| 星光封印 | 星星的星屑彈打亮 | 星王留下的封印，只認星星的光 |
- 第一次來的時候還沒有那個形態，就先記著，之後帶新形態回來拿寶物。

### 3.4 祭壇（存檔點）
- 「星之祭壇」：墜落的星星碎片插在地上形成的小祭壇，碰到會點亮。
- 點亮後回滿血、記錄位置；死掉從最後點亮的祭壇重來。
- 📝 祭壇之間可以傳送（之後再說）。

### 3.5 地圖畫面
- 按 M（手機在選單裡）打開；走過的地方才會顯示。
- 標記：祭壇、出口、還沒拿的一次性資源（拿過就變灰）、還沒開的形態機關。

- 魔力不夠時按了沒反應、魔力條閃一下；祭壇和死掉重來會回滿。
