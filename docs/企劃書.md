# 《零星勇者》遊戲企劃書（暫定名）

> 版本 v0.2 · 2026-11-03（世界觀大改：主角改成轉生的星星碎片；加入冒險者公會與城鎮）
> 舊版（人類主角、召喚與深淵設定）保留在 `企劃書-v0.1-人類主角.md`。
> 類型：橫向卷軸動作 RPG（線性關卡＋劇情、刷怪練等、刷寶、探索、城鎮據點）
> 平台：網頁（電腦＋手機），單機，預計商用
> 風格：輕鬆搞笑的吐槽風轉生異世界

---

## 0. 一句話

轉生成一小塊**星星碎片**的勇者，在魔物與各種族共存的世界裡，打倒被星星力量弄瘋的狂化魔物、吸收牠們的力量變換形態，從冒險者公會的 F 級一路爬到最強。

### 設計支柱
1. **爽**：怪多、技能狂放、打擊感強；手機上單手移動、單手打就能爽。
2. **變**：吸收魔物的力量切換形態，每個形態有不同的外型、普攻和技能。打新魔物＝拿到新玩法。
3. **撿**：裝備、星核、材料全部靠撿，每一次掉寶都要讓人期待。
4. **笑**：系統吐槽、居民對話、物品說明處處有梗，但不拖節奏。

## 1. 世界觀

### 1.1 背景：星落事件
- 這個世界本來就住著各式各樣的種族與魔物：史萊姆、魔像、蘑菇族、鳥人、精靈、骷髏……人類不是主角，也不一定存在。
- 很久以前發生了「**星落**」：天上掉下大量星星碎片，散落在大地各處。
- 有些野外生物吸收了碎片的力量後失控暴走，稱為「**狂化魔物**」。牠們是冒險者要討伐的對象。
- 城鎮裡的居民是沒受影響、正常生活的各種族。**同樣是史萊姆，野外的會咬人，公會櫃檯的會幫你蓋章。**
- 打倒狂化魔物時，牠體內的碎片力量會被釋放出來，魔物本身恢復正常（逃走或消失）。所以討伐其實是「淨化」。

### 1.2 主角
- 上輩子的身分刻意留白，只知道死後**轉生成一小塊星星碎片**，從天上掉下來。
- 外型：圓胖的星星身體，短短的手腳，兩顆眼睛。造型詳見第 9 章。
- 特殊體質：身為碎片，能把狂化魔物身上的碎片力量**吸收**成自己的「**形態**」，切換形態就能使用那種魔物的能力（第 3 章）。
- 個性：嘴賤、樂天、適應力超強（「變成星星？好喔。」）。

### 1.3 「系統」：吐槽擔當
- 只有主角聽得到的聲音，負責教學、提示和吐槽。說話很毒，但其實很關心主角。
- 範例：
  - 剛轉生：「恭喜轉生成功。種族：星星。……不，我也是第一次看到。」
  - 第一次吸收形態：「你把史萊姆吃掉了？不對，是吸收。好吧，差不多。」
  - 公會登記時：櫃檯「種族欄要填什麼？」系統：「填『發光的五角形』應該就好。」
  - 連續死三次：「要不要考慮回天上去？我可以幫你叫流星。」
- 伏筆：系統其實是主角這塊碎片原本的「星之意識」，最終章揭曉。

### 1.4 主線劇情（5 章，暫定）
每章一個「被看不起 → 用新形態逆轉」的高潮。

| 章 | 舞台 | 劇情 | 王 | 代表形態 |
|---|---|---|---|---|
| 1 | 墜星之谷 | 轉生、掉進魔物洞窟、系統登場、第一次吸收形態；走出洞窟抵達碎星鎮 | **大胃王史萊姆**（吃垃圾長大的狂化巨型史萊姆） | 黏液星、鐵罐星 |
| 2 | 碎星鎮與迷霧森林 | 登記冒險者（F 級，被嘲笑「是飾品吧？」）；森林魔物潮，靠自己清光 | **森林老大·熊老闆**（狂化的暴躁熊） | 尖刺星、蝠翼星 |
| 3 | 熔岩礦坑 | 公會升級考試；發現有人在故意收集星星碎片 | **熔岩魔像** | 鐵鎚星、火焰星 |
| 4 | 浮空遺跡 | 星落的真相：碎片是一顆巨大星星碎掉的殘骸 | **遺跡守護者** | 雷光星 |
| 5 | 星墜之地 | 最大的碎片吸收了太多力量而狂化，自稱「星王」；它是主角的另一半 | **星王** | 終章 |

- 章與章之間回到**碎星鎮**整備、接任務、看劇情（第 7 章）。
- 搞笑原則：每段劇情對話以 6～10 句為上限，可以快轉跳過。

## 2. 核心循環

```
  城鎮：在公會接任務、整備裝備與形態
     ↓
  出任務：打狂化魔物（快節奏、怪多）
     ↓
  撿：金幣、經驗、裝備、魔物核全部飛向你
     ↓
  回城鎮：交任務升公會等級、工坊強化、研究所升級形態
     ↓
  變強 → 解鎖新區域與更難的任務 ──→ 回到出任務
```

## 3. 主角能力：形態系統

### 3.1 吸收與形態
- 打倒狂化魔物時，有機率掉出「**魔物核**」（菁英怪、王必掉）。撿起來就**解鎖**那種魔物的形態。
- 撿到已經有的核：那個形態**經驗增加**，升級後數值變強，Lv5、Lv10 外觀升級（換顏色、變大）。
- 戰鬥中最多**帶 3 個形態**，按一個鍵輪流切換；切換瞬間有短暫無敵和一個小爆光。
- 在城鎮的形態研究所（7.3）決定要帶哪 3 個。

### 3.2 形態一覽（取代舊版的武器種類）
每個形態改變**外型、手腳、普攻連段、形態技能**。舊版 5 種武器的攻擊節奏分配到形態上，程式可以沿用。

| 形態 | 來源 | 外型變化 | 普攻（按住連段） | 形態技能 | 手感（對應舊武器） |
|---|---|---|---|---|---|
| **星星**（基本） | 一開始就有 | 原本的樣子 | 拳打＋旋轉撞擊 | 星屑彈（直線） | 單手劍：均衡 |
| **尖刺星** | 刺蝟類 | 五個角變長變尖，手變尖爪 | 連續突刺，快、暴擊高 | 刺球衝刺 | 雙匕首／長槍 |
| **鐵鎚星** | 魔像類 | 身體變方、手變大拳頭 | 往下砸，慢、範圍大、擊飛 | 跳起重壓地面 | 大錘／大劍 |
| **黏液星** | 史萊姆 | 軟軟彈彈、會滴 | 黏液甩擊，中距離 | 分裂彈跳 | 鞭 |
| **蝠翼星** | 蝙蝠 | 手變小翅膀 | 空中連擊，空中可多停一下 | 短距離飛行 | 拳爪 |
| **鐵罐星** | 垃圾桶怪 | 套上鐵罐外殼，蓋子當嘴 | 蓋子咬 | 往前衝撞，衝撞時擋傷害 | 大劍 |
| **火焰星** | 火類魔物 | 全身著火 | 火拳 | 火球（現有） | 魔導槍 |

- 目標：主線約 12 種形態，之後擴充。
- **形態技能**是冷卻制；**大招「零星墜落」**是所有形態共用的終極技（能量條集滿才能放，已實作）。

### 3.3 元素反應
敵人身上同時有兩種狀態時觸發反應，鼓勵切換形態搭配：

| 組合 | 反應 | 效果 |
|---|---|---|
| 冰凍＋雷 | 碎裂 | 大量傷害，冰屑濺射周圍 |
| 燃燒＋黏液 | 爆燃 | 原地爆炸，連鎖引燃附近沾黏液的敵人 |
| 濕潤＋雷 | 感電擴散 | 雷傷害傳給附近所有濕潤的敵人 |
| 星光＋任何狀態 | 星爆 | 淨化狀態，造成星光傷害 |

## 4. 戰鬥與操作

### 4.1 手機操作
```
┌──────────────────────────────────────────────┐
│ ♥  Lv12  ▓▓▓▓▓░ 大招        [形態1][形態2][形態3]│
│                                              │
│              （遊戲畫面）                     │
│                                              │
│    ↑ 往上滑＝跳（空中再滑＝二段跳）    [大招][技能]  │
│  ◀  左右拖＝移動  ▶                             │
│    ↓ 往下滑＝穿過平台           [閃避]  [攻擊]   │
└──────────────────────────────────────────────┘
```
- **左半螢幕**：左右拖移動，往上快滑跳躍，往下快滑穿過平台；不用抬起手指。
- **右半螢幕**：攻擊（按住自動連段）、閃避（無敵時間）、形態技能（自動瞄準）、大招（能量滿才亮）。
- **形態切換**：點右上角的形態圖示直接切到那個形態。

### 4.2 電腦操作
| 動作 | 鍵盤 |
|---|---|
| 移動 | A / D（或方向鍵） |
| 跳 | W / 空白鍵 |
| 穿過平台 | S＋跳 |
| 攻擊（按住連段） | J |
| 閃避 | K |
| 形態技能 | U |
| 切換形態 | O（輪流）、1 / 2 / 3（直接選） |
| 大招 | L |
| 背包 | I |
| 和 NPC 對話（城鎮） | W 或 J |

### 4.3 爽感清單
- 命中停頓、畫面震動、敵人擊飛；傷害數字，暴擊大字。
- 掉落物四散後自動吸向主角。
- 連擊數：連擊 50、100、200 時有系統吐槽。
- 切換形態時的變身演出要短而有力（0.15 秒內），可以在連段中切換接技。
- 大招全螢幕演出（已實作：起承轉合、暗場、特寫帶、黑白衝擊定格）。

### 4.4 敵人設計原則
- **雜兵**：數量多、血少，負責讓玩家爽。
- **菁英怪**：名字前掛隨機稱號，帶 1～2 個特殊詞綴，必掉魔物核。
- **王**：招式有明顯預兆；王的招式就是打贏後吸收到的形態技能，讓玩家「先被打，再拿來打人」。
- **金幣史萊姆**：一出現就拼命逃跑，打爆噴一地金幣。
- 狂化魔物的共通視覺：身上有發光的星星碎片（例如眼睛發金光、身上卡著碎片），和城鎮裡的同種族居民區分。

## 5. 刷寶系統（重點）

### 5.1 裝備欄位（星核主題）
主角有手有腳，所以保留四個部位，名稱換成符合世界觀的說法：

| 欄位 | 說明 | 舊版對應 |
|---|---|---|
| 星冠 | 頭頂的裝飾（光環、皇冠、小帽子） | 頭盔 |
| 星殼 | 身體外層 | 衣服 |
| 星爪 | 手套、護手 | 手套 |
| 星靴 | 鞋子 | 鞋子 |
| 碎片 ×2 | 偏向特殊效果、觸發類詞綴 | 飾品 |

- 武器欄取消，攻擊方式由**形態**決定（3.2）。攻擊力改由「星核等級」與裝備詞綴提供。
- 稀有度、詞綴、傳說、套裝、自動拆解、一鍵比較全部沿用 M3 已完成的系統。

### 5.2 稀有度
| 稀有度 | 顏色 | 詞綴數 | 掉落演出 |
|---|---|---|---|
| 垃圾 | 灰 | 0 | 「啪」一聲掉在地上 |
| 普通 | 白 | 0～1 | 小閃光 |
| 魔法 | 藍 | 1～2 | 藍色光柱 |
| 稀有 | 黃 | 3～4 | 黃色光柱 |
| 傳說 | 橘 | 2～3＋**獨特效果** | 橘色光柱衝天、畫面一閃、時間短暫變慢 |
| 套裝 | 綠 | 2～3＋套裝效果 | 綠色光柱 |
| 墜星遺物 | ？ | ？？？ | 掉出來是一團灰灰的石頭，但會微微發光 |

### 5.3 詞綴
- 每個詞綴有 T1～T5 層級，數值在範圍內隨機。
- 分類：基礎（攻擊、生命、防禦、攻速、移速）、暴擊、元素、狀態、觸發（擊殺時爆炸等）、形態（某形態傷害 +X%、切換形態後 3 秒攻擊 +X%）、拾取（掉寶率、金幣、吸物範圍、魔物核掉率）。
- **智慧掉落**：約 60% 的裝備偏向玩家目前帶的形態。

### 5.4 墜星遺物（取代舊版的封印遺物）
- 星落時，有些碎片附著在物品上，變成灰灰的石頭。它們是**更早墜落的星星**留下的東西。
- 每件遺物有一個**解封條件**，例如「用鐵鎚星擊殺 500 個敵人」「不受傷打倒一隻王」，進度即時顯示。
- 解封後變成擁有獨特機制的強力裝備，並解鎖一段那顆星星的故事，慢慢拼出星落的真相與星王的身世。

### 5.5 傳說範例
| 名稱 | 欄位 | 獨特效果 |
|---|---|---|
| 藍白拖星靴 | 星靴 | 閃避後的下一擊必定暴擊；閃避距離 +50% |
| 加班證明 | 碎片 | 戰鬥持續越久傷害越高：每 10 秒 +5%，上限 +100% |
| 史萊姆王冠 | 星冠 | 擊殺的敵人有 20% 機率變成小史萊姆替你作戰 |
| 很吵的光環 | 星冠 | 每 10 秒吐槽一次並給予隨機增益 |

### 5.6 避免挫折
- 保底：沒掉傳說的菁英怪會讓下次機率提高。
- 公會懸賞板每日刷新（7.2）。
- 自動拆解、一鍵比較與穿戴（已實作）。

## 6. 成長與練等

- **角色等級**：主線上限 Lv50，升級提升基礎數值並得到天賦點。天賦分三系：戰鬥、生存、星光（形態、掉寶、大招）。
- **形態等級**：每個形態各自 Lv1～Lv10，靠吸收重複的核或在研究所用材料升級。
- **公會等級**：F → E → D → C → B → A → S，靠完成任務升級，解鎖新區域、新任務和城鎮新設施。
- **難度**：普通 → 困難（通關該章）→ 星墜（通關主線，怪物帶隨機詞綴）。
- **終局**：「星墜裂縫」無限層挑戰，每日裂縫、本機排行榜。

## 7. 城鎮：碎星鎮

### 7.1 城鎮概要
- 建在一個巨大隕石坑旁邊的小鎮，各種族混居。因為星落而出現冒險者公會，專門處理狂化魔物。
- **可以走動的橫向小鎮**，使用跟關卡同一套引擎與光影，約 2～3 個畫面寬，不能戰鬥。
- 走到 NPC 或建築旁邊，頭上出現提示，按鍵（手機：點一下提示）就對話或打開功能。
- 城鎮的氣氛要跟關卡相反：溫暖、明亮、有路燈和窗戶的光、居民走來走去。

### 7.2 設施（第一版先做前三個）
| 設施 | NPC | 功能 | 對應現有系統 |
|---|---|---|---|
| **冒險者公會** | 櫃檯：戴眼鏡的冷靜大史萊姆 | 登記、接任務、交任務、公會等級、懸賞板 | 關卡、通關獎勵 |
| **星核工坊** | 老闆：手很大的石頭魔像 | 拆解、強化、重鑄、合成 | 背包、拆解碎屑 |
| **旅館** | 老闆娘：大蘑菇，傘蓋上長著小蘑菇 | 存檔、回滿血、看劇情回顧 | 自動存檔 |
| 形態研究所（第二版） | 很聒噪的貓頭鷹學者 | 查看、升級、選擇攜帶的形態 | 形態系統 |
| 商店（之後） | 待定 | 用金幣買補給和外觀 | 金幣 |

### 7.3 冒險者公會
- **登記**：第 2 章開頭的劇情。櫃檯問種族，系統吐槽；拿到 F 級冒險者證。
- **任務種類**：
  - 討伐：打倒指定魔物或王（關卡）。
  - 採集：在關卡裡撿指定材料。
  - 調查：走到關卡最深處、找到隱藏房間。
- **懸賞板**：每日（依裝置時間）刷新，例如「討伐 30 隻狂化史萊姆」，獎勵指定部位的寶箱。
- **升級考試**：每升一級有一場考試關卡，通過才升級。

### 7.4 居民
- 第一版：公會櫃檯、工坊老闆、旅館老闆娘，加上 2～3 個會走來走去、點了會講一句話的路人（小精靈、骷髏郵差、蜥蜴商人等）。
- 居民對話以吐槽風為主，會隨劇情進度和主角的公會等級改變。
- 每個居民都要遵守規則v2 繪製（剪影清楚、1px 描邊、8 幀待機）。

## 8. 第一章詳細規劃（原型範圍）

### 8.1 第一章：墜星之谷

## 9. 美術與特效

### 9.1 美術策略
| 項目 | 方式 |
|---|---|
| 主角、NPC、敵人 | **自己用程式／手繪像素繪製，遵守 `終極版規則v2.txt`**（剪影優先、1px 描邊、不抗鋸齒、8 幀待機） |
| 特效 | PixelFX 特效庫（MIT）＋自製；特效與場景光**不受**規則v2 限制，可以用柔光、漸層、半透明 |
| 場景 | 程式繪製的多層視差場景＋柔和光影（已實作洞窟） |
| 字型 | 可商用的開源像素中文字型（候選：俐方體 11 號、縫合像素字型，使用前再確認） |
| 音樂、音效 | 可商用的開源素材，或之後委託 |

### 9.2 主角造型方向
- 圓胖的星星身體（五個角圓鈍），短手短腳，兩顆眼睛；身體本身微微發光。
- 主色淡金色，搭配一個識別色（候選：青色或紅色圍巾），避免和任何知名角色相似（不用粉紅色圓球、不用黃色五角星臉）。
- 換形態時，身體輪廓與手腳一起改變，但眼睛和識別色保留，讓玩家一眼認得是同一個主角。
- 所有素材製作前先找多個參考（`docs/素材參考.md`）。

### 9.3 系統與特效對照
| 遊戲功能 | 特效 |
|---|---|
| 受擊、暴擊、傷害數字 | `impacts/hit-spark`、`impacts/crit-hit`、`ui/damage-number` |
| 敵人死亡（淨化） | `spawn/poof`、`spawn/soul-rise`，加上碎片飛出 |
| 吸收魔物核 | `shadow/soul-drain` 反向＋`arcane/mana-burst` |
| 切換形態 | `arcane/blink-in` 改色＋自製星光爆開 |
| 掉落光柱、金幣、寶箱、升級 | 已實作 |
| 大招 | 已實作（`game/src/ult.js`） |
| 城鎮氣氛 | `weather/fireflies`、`fire/torch`、`fire/candle` |

## 10. 技術規格

| 項目 | 規格 |
|---|---|
| 技術 | HTML5 Canvas 2D＋JavaScript（ES 模組），不使用遊戲引擎 |
| 內部解析度 | 高度 216 像素，寬度依螢幕比例 320～480，整數倍放大，`image-rendering: pixelated` |
| 更新頻率 | 固定 60 次/秒的遊戲邏輯 |
| 特效 | 高頻特效預先轉成精靈圖；大招等低頻特效即時運算 |
| 效能目標 | 中階手機：同時 60 隻敵人、30 個特效、維持 60 fps |
| 存檔 | 瀏覽器本機儲存，自動存檔；可匯出／匯入存檔碼 |
| 離線 | 做成 PWA |
| 發布 | itch.io 或自架網站 |
