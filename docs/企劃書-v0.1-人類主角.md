# 《零星勇者》遊戲企劃書（暫定名）

> 版本 v0.1 · 2026-11-03
> 類型：橫向卷軸動作 RPG（線性關卡＋劇情、刷怪練等、刷寶、探索）
> 平台：網頁（電腦＋手機），單機，預計商用
> 風格：輕鬆搞笑的爽文逆襲異世界

---

## 0. 一句話

被王國判定「零星廢物」而丟進深淵的召喚者，靠著只能撿東西的技能「拾荒」，把魔物的招式、前人的遺物、滿地的垃圾全部撿起來，一路撿成最強。

### 設計支柱
1. **爽**：怪多、技能狂放、打擊感強；手機上單手移動、單手打就能爽。
2. **撿**：所有成長都來自「撿」，包括招式、裝備、遺物和材料。每一次掉寶都要讓人期待。
3. **笑**：系統吐槽、物品說明、敵人稱號、劇情打臉，處處有梗，但不拖節奏。

## 1. 世界觀

### 1.1 背景
- **艾爾德蘭王國**定期從異世界召喚「勇者」當作對抗魔王的兵器。
- 被召喚的人依「技能星等」分級。星等低的被視為廢物，丟進王都底下的大裂谷「**深淵**」處理掉。
- 這件事進行了好幾百年，所以深淵裡埋著無數**前代被拋棄者的遺物**。這也是深淵寶物特別多的原因，後面會變成刷寶與劇情的核心。

### 1.2 主角
- 與三名同學一起被召喚。同學拿到「劍聖」、「大賢者」、「聖女」，主角只有一個技能：**「拾荒」，零星**。
- 主角性別、外觀由玩家選擇，並選一件「穿越時手上的東西」（見第 3 章「本命物」）。
- 個性：嘴賤、樂天、非常務實，看到東西就想撿。

### 1.3 「系統」：吐槽擔當
- 只有主角聽得到的系統聲音，負責教學、提示和吐槽。
- 說話很毒，但其實很關心主角。
- 範例：
  - 撿到垃圾：「恭喜獲得〈史萊姆的鼻涕〉×37。我真心不知道你要這幹嘛。」
  - 第一次偷到招式：「……等等，這不在規格書上。」
  - 連續死三次：「要不要考慮回去當廢物？我可以幫你寫推薦信。」
- 伏筆：系統其實是「拾荒」技能本身的意識，最終章揭曉。

### 1.4 主線劇情（5 章）
每章一個「被看不起 → 逆襲打臉」的高潮。

| 章 | 舞台 | 劇情 | 王 | 偷到的代表招式 | 解鎖的探索能力 |
|---|---|---|---|---|---|
| 1 | 深淵·廢棄者之谷 | 被丟下深淵、覺醒「拾荒」，系統登場 | **大胃王史萊姆**（吃垃圾長大的巨型史萊姆） | 火球投擲 | 燒掉藤蔓與蛛網 |
| 2 | 邊境·雷維鎮與迷霧森林 | 公會說零星不能登記冒險者，主角一個人清掉森林魔物潮 | **森林老大·熊老闆**（自稱森林之王的暴躁熊人） | 冰槍投擲 | 凍結水面與瀑布 |
| 3 | 帝國競技場 | 與當年嘲笑他的「劍聖」同學對決，全場倒戈 | **劍聖·同學A** | 劍技連段、衝刺斬 | 衝破裂牆、空中衝刺 |
| 4 | 王都 | 「大賢者」與「聖女」揭開王國把勇者當兵器的真相；聖女加入 | **大賢者·同學B** | 隕石召喚、雷擊召喚 | 啟動古代機關 |
| 5 | 魔王城 | 魔王是**初代被拋棄的召喚者**，也擁有「拾荒」 | **魔王·初代拾荒者** | 黑洞、時間停止 | 終章 |

- 章與章之間：營地「拾荒小屋」是主角的據點，可以整備裝備、鍛造、看劇情。
- 搞笑原則：每段劇情對話以 6～10 句為上限，可以快轉跳過。

## 2. 核心循環

```
  打怪（快節奏、怪多）
     ↓
  撿（金幣、經驗、裝備、殘響、遺物、垃圾全部飛向你）
     ↓
  回營地：鑑定、鍛造、餵本命物、配招
     ↓
  變強 → 用新招打開新路、挑戰更高難度
     ↓
  更強的怪、更好的寶 ──→ 回到打怪
```

## 3. 主角能力

主角能力由三層組成：**拾荒（固有）＋本命物（玩家選擇）＋殘響（偷來的招式）**。

### 3.1 拾荒（固有能力，隨劇情解鎖）
| 階段 | 解鎖時機 | 能力 |
|---|---|---|
| 撿 | 開場 | 範圍內掉落物自動飛向主角 |
| 偷 | 第 1 章中段 | 菁英怪和王死亡時有機率留下「殘響」，撿起來就學會牠的招式 |
| 鑑 | 第 1 章結尾 | 在營地鑑定未知物品 |
| 合 | 第 2 章 | 解鎖鍛造工坊：拆解、重鑄、合成 |
| 解封 | 第 2 章 | 封印遺物開始累積解封進度（見 5.6） |
| 萬象拾遺 | 第 3 章 | 大招：把裝備中的殘響一口氣全部放出來 |

另有一條獨立成長線「**拾荒等級**」，見 6.2。

### 3.2 本命物：穿越時手上拿的東西
開場時玩家選擇主角性別、外觀，以及「被召喚那一刻手上拿著什麼」。這件東西會變成**本命物**：
- 佔一個專屬裝備欄，**不會掉落、不會被取代**，會跟著主角一起成長。
- 每件本命物有自己的**主動技能**、**被動特性**和**進化樹**。
- 進化的材料是**垃圾**，讓垃圾也有價值。
- 決定主角的**流派傾向**，但不限制武器：任何本命物都能拿任何武器。
- 其他本命物會在劇情中陸續找到，可以在營地切換，所以一開始的選擇不會錯，只是起點不同。

| 本命物 | 被動特性 | 主動技能（右手技能鍵之一） | 進化方向（第 2 階分支） | 搞笑點 |
|---|---|---|---|---|
| **手機**（電量 3%） | 撿到的物品**立刻鑑定**；可以看到敵人的弱點屬性 | 「閃光拍照」：前方扇形致盲並暈眩敵人 | 雷霆終端（雷系、連鎖閃電）／天眼（暴擊、弱點擊破） | 永遠 3% 電量但從來不會沒電。系統：「這不合理，但我懶得管了。」 |
| **拖把** | 吸物範圍 ×2；普攻多一段橫掃擊退 | 「大掃除」：在身邊捲起旋風，把敵人和掉落物一起捲過來 | 暴風掃帚（風、聚怪）／聖水拖把（水、淨化治療） | 角色說明：「被召喚時正在打掃教室，所以我是值日生勇者。」 |
| **雨傘** | 閃避改為「開傘」：短時間格擋，完美時機會反彈投射物 | 「傘擊」：收傘突刺，命中後彈開回到原位 | 天蓋（聖盾、團隊護盾）／鐵骨傘（反擊、硬派） | 傘骨斷了一根，每次開傘都會「啪」一聲。 |
| **外送保溫箱** | 背包容量 +50%；商店購買打 8 折 | 「爆量外送」：把箱子丟出去爆炸，炸出隨機補給 | 空投無人機（召喚、追蹤飛彈）／超重載（爆炸、範圍） | 箱子裡永遠有一份不知道是誰的便當，吃了回血。 |

> 設計重點：本命物讓「選角」有實際的玩法差異，又不鎖死玩家。進化需要大量垃圾，所以刷怪時撿到的每一件垃圾都有用處。

### 3.3 殘響：偷來的招式
- 從菁英怪、王身上偷到的招式，放進 **2 個主動技能欄**。
- 殘響本身也是**掉落物**，有等級、品質和**變異詞綴**，詳見 5.5。
- 招式圖鑑對應 PixelFX 特效庫，目標收集 60 種以上。

### 3.4 元素反應
敵人身上同時有兩種狀態時，會觸發反應，鼓勵玩家搭配招式：

| 組合 | 反應 | 效果 |
|---|---|---|
| 冰凍＋雷 | 碎裂 | 大量傷害，冰屑濺射周圍 |
| 燃燒＋中毒 | 爆燃 | 原地爆炸，連鎖引燃附近中毒的敵人 |
| 濕潤＋雷 | 感電擴散 | 雷傷害傳遞給附近所有濕潤的敵人 |
| 詛咒＋聖光 | 淨化 | 敵人被擊殺時爆出一圈治療 |

## 4. 戰鬥與操作

### 4.1 手機操作
```
┌──────────────────────────────────────────────┐
│ ♥♥♥♥  Lv12  ▓▓▓▓▓░ 大招                  ⏸   │
│                                              │
│              （遊戲畫面）                     │
│                                              │
│    ↑ 往上滑＝跳（空中再滑＝二段跳）  [殘響1][殘響2]│
│  ◀  左右拖＝移動  ▶                  [本命][大招]  │
│    ↓ 往下滑＝穿過平台           [閃避]  [攻擊]   │
└──────────────────────────────────────────────┘
```
- **左半螢幕**：手指放在任何位置都能操作，左右拖移動，往上快滑跳躍，往下快滑穿過平台；不用抬起手指。
- **右半螢幕**：
  - 攻擊：**按住自動連段**，不用狂點。
  - 閃避：帶無敵時間；沒有推方向時，自動往遠離敵人的方向閃。
  - 殘響 1、殘響 2、本命技能：冷卻制，**自動瞄準最近的敵人**。
  - 大招：能量滿了才會亮。
- 設定選項：跳躍改成左側按鈕、按鍵大小與透明度、按鍵位置自訂、震動開關。

### 4.2 電腦操作
| 動作 | 鍵盤 | 手把 |
|---|---|---|
| 移動 | A / D（或方向鍵） | 左搖桿 |
| 跳 | W / 空白鍵 | A |
| 穿過平台 | S＋跳 | 下＋A |
| 攻擊（按住連段） | J | X |
| 閃避 | K | B |
| 殘響 1 / 2 | U / I | LB / RB |
| 本命技能 | O | Y |
| 大招 | L | LT＋RT |

### 4.3 爽感清單
- 命中停頓、畫面震動、敵人擊飛：使用 PixelFX 特效附帶的動作時機參數（蓄力、命中停頓、收招）。
- 傷害數字噴出，暴擊用大字。
- 敵人一倒，掉落物四散後自動吸向主角。
- 連擊數：越高特效越華麗，連擊 50、100、200 時有系統吐槽和額外獎勵。
- 「擊殺時爆炸」之類的詞綴會在怪群中連鎖觸發。
- 大招全螢幕演出：時間短暫變慢、背景變暗、特效齊放。

### 4.4 敵人設計原則
- **雜兵**：數量多、血少、一兩刀就倒，負責讓玩家爽。
- **菁英怪**：名字前掛隨機稱號，帶 1～2 個特殊詞綴，掉寶率高，可能留下殘響。
- **王**：招式有明顯預兆；每隻王的招式就是玩家之後能偷到的招式，讓玩家「先被打，再拿來打人」。
- **金幣史萊姆**：偶爾出現，一出現就拼命逃跑，打爆會噴一地金幣。

## 5. 刷寶系統（重點）

### 5.1 裝備欄位
| 欄位 | 說明 |
|---|---|
| 武器 | **決定普攻連段的招式**（見 5.2） |
| 頭盔、衣服、手套、鞋子 | 防禦與數值詞綴 |
| 飾品 ×2 | 偏向特殊效果、觸發類詞綴 |
| 本命物 | 專屬欄，見 3.2 |
| 殘響 ×2 | 主動技能，見 5.5 |

### 5.2 武器種類：換武器＝換玩法
| 武器 | 普攻特性 | 對應特效 |
|---|---|---|
| 單手劍 | 均衡，三段快斬 | `melee/sword-slash`、`melee/double-slash` |
| 大劍 | 慢、重、範圍大 | `melee/heavy-cleave` |
| 雙匕首 | 極快多段，暴擊高 | `melee/dagger-flurry` |
| 長槍 | 距離長，突刺 | `melee/thrust`、`melee/spear-sweep` |
| 大錘 | 震地，擊飛 | `melee/hammer-smash`、`impacts/ground-slam` |
| 鐮刀 | 大弧度橫掃，吸血 | `melee/scythe-reap` |
| 鞭 | 中距離，多目標 | `melee/whip-crack` |
| 拳爪 | 近身連打，上勾拳浮空 | `melee/claw-swipe`、`melee/uppercut` |
| 弓 | 遠程 | `moves/arrow-shot`、`projectiles/arrow` |
| 魔導槍 | 遠程連射 | `moves/pistol-shots`、`projectiles/bullet-tracer` |

### 5.3 稀有度
| 稀有度 | 顏色 | 詞綴數 | 掉落演出 | 初版機率（一般怪） |
|---|---|---|---|---|
| 垃圾 | 灰 | 0 | 「啪」一聲掉在地上 | 45% |
| 普通 | 白 | 0～1 | 小閃光 | 35% |
| 魔法 | 藍 | 1～2 | 藍色光柱 | 15% |
| 稀有 | 黃 | 3～4 | 黃色光柱＋音效 | 4.5% |
| 傳說 | 橘 | 2～3＋**獨特效果** | 橘色光柱衝天、畫面一閃、時間短暫變慢 | 0.45% |
| 套裝 | 綠 | 2～3＋套裝效果 | 綠色光柱＋專屬音效 | 0.05% |
| 封印遺物 | ？ | ？？？ | 掉出來是一團破爛，但地上冒黑紫色的氣 | 只從特定來源（見 5.6） |

- 菁英怪掉寶率 ×3，王 ×10 且必掉一件稀有以上。
- 機率是初版數值，之後依測試調整。

### 5.4 詞綴
**物品等級**：由關卡與難度決定，決定詞綴的數值上限。

**詞綴分層**：每個詞綴有 T1～T5 五個層級，數值在範圍內隨機。高層級、高數值的「完美詞綴」會讓玩家一直想刷。

**詞綴分類與範例**
| 類別 | 範例 |
|---|---|
| 基礎 | 攻擊 +X%、生命 +X、防禦 +X、攻速 +X%、移速 +X% |
| 暴擊 | 暴擊率 +X%、暴擊傷害 +X% |
| 元素 | 附加火／冰／雷／聖／暗／自然傷害；某元素傷害 +X% |
| 狀態 | 攻擊有 X% 機率使敵人燃燒／冰凍／感電／中毒／流血 |
| 觸發 | 擊殺時爆炸、每第 3 擊落雷、閃避時留下冰霜、受擊時放出荊棘 |
| 技能 | 某殘響傷害 +X%、某殘響冷卻 -X%、殘響範圍 +X% |
| 拾荒 | 掉寶率 +X%、金幣 +X%、吸物範圍 +X%、殘響掉落率 +X% |

**智慧掉落**：約 60% 的裝備會偏向玩家目前使用的武器種類與元素，避免一直撿到用不到的東西。

### 5.5 殘響（技能）也是寶
- 殘響有**等級**（Lv1～Lv10）：撿到重複的殘響就會升級，Lv5、Lv10 時外觀升級，例如換顏色、範圍變大。
- 殘響有**品質**：普通、精良、完美，影響基礎數值。
- 殘響有**變異詞綴**（稀有掉落）：

| 變異 | 效果 | 範例 |
|---|---|---|
| 分裂 | 投射物分成 3 發 | 三連火球 |
| 追蹤 | 自動追敵 | 追蹤冰槍 |
| 連鎖 | 命中後跳到下一個敵人 | 連鎖落雷 |
| 巨大化 | 範圍 ×1.5，冷卻加長 | 巨型隕石 |
| 元素轉換 | 改變屬性與顏色 | **藍色冰火球**（PixelFX 換調色板即可） |
| 回音 | 1 秒後再放一次 | 二連地刺 |

### 5.6 封印遺物：前代被拋棄者留下的東西
深淵裡埋著幾百年來被拋棄的召喚者的遺物。它們被深淵的力量封印，看起來只是破爛，例如〈生鏽的斷劍〉、〈發霉的圍巾〉、〈裂開的眼鏡〉。

- **來源**：王（5%）、隱藏房間、深淵裂縫高層、特定菁英怪。
- **解封條件**：每件遺物各有一個條件，進度會即時顯示。
  - 〈生鏽的斷劍〉：用它擊殺 500 個敵人（0 / 500）
  - 〈發霉的圍巾〉：在不受傷的情況下打倒一隻王
  - 〈裂開的眼鏡〉：觸發 100 次元素反應
- **解封後**：變成擁有獨特機制的強力裝備，並解鎖一段原主人的故事，例如「第 37 代被拋棄者，技能『鬧鐘』，零星」。
- **為什麼這樣設計**：
  - 不是「掉出來就爽完」，而是**撿到後還有一段期待**，玩家會為了解封改變打法。
  - 把世界觀的歷史藏在遺物裡，越刷越懂這個世界，最後連到魔王的身世。
  - 呼應主題：被看不起的破爛，其實是寶。

### 5.7 傳說與套裝範例
**傳說裝備**（獨特效果會改變打法）
| 名稱 | 欄位 | 獨特效果 |
|---|---|---|
| 前任勇者的拖鞋 | 鞋子 | 閃避後的下一擊必定暴擊；閃避距離 +50% |
| 加班證明 | 飾品 | 戰鬥持續越久傷害越高：每 10 秒 +5%，上限 +100%，離開戰鬥歸零 |
| 史萊姆王冠 | 頭盔 | 擊殺的敵人有 20% 機率變成小史萊姆替你作戰 |
| 過期的聖水 | 飾品 | 治療效果改為對周圍造成聖屬性傷害 |
| 很吵的劍 | 單手劍 | 每 10 秒吐槽一次並給予隨機增益；「拜託你認真打好嗎」 |

**套裝範例：深淵清潔隊**（4 件）
- 2 件：吸物範圍 +100%
- 4 件：每撿起一件物品，朝最近的敵人發射一枚魔法飛彈（`projectiles/magic-missile`）

### 5.8 鍛造工坊（營地）
| 功能 | 說明 |
|---|---|
| 鑑定 | 魔法以上的裝備從菁英怪和王身上掉下時是「未鑑定」，回營地鑑定才揭曉；手機本命物可以直接鑑定 |
| 拆解 | 裝備 → 材料；垃圾 → 「垃圾碎屑」（本命物進化材料） |
| 重鑄 | 指定一個詞綴重新隨機（每件裝備可重鑄的次數有限，避免無限洗） |
| 強化 | +1～+10，提升基礎數值；+7 以上有失敗機率但不會壞，只會掉回 +6 |
| 合成 | 指定材料＋垃圾，合成特定部位的隨機裝備；系統吐槽：「三根魚骨加一隻破鞋，你確定？」 |

### 5.9 避免挫折
- **保底**：每打倒一隻沒掉傳說的菁英怪，下一次的傳說機率就提高一點，掉出後歸零。
- **王的專屬掉落**：每隻王有 2～3 件專屬傳說，可以指定重刷。
- **懸賞板**：營地每日（依裝置時間）刷新懸賞，例如「討伐 30 隻火屬性敵人」，獎勵指定部位的寶箱。
- **自動處理**：設定低於某稀有度的裝備自動拆解，手機玩家不用一直整理背包。
- **一鍵比較與穿戴**：新裝備比身上的好時顯示綠色箭頭，一鍵換上。

## 6. 成長與練等

### 6.1 角色等級
- 主線上限 Lv50，打怪拿經驗，升級提升基礎數值，並得到 1 點天賦點。
- 天賦樹分三系：**戰鬥**（攻擊、暴擊、攻速）、**生存**（生命、防禦、閃避）、**拾荒**（掉寶、金幣、殘響、本命物）。

### 6.2 拾荒等級（滿級後的無限成長）
- Lv50 之後，經驗轉為「拾荒等級」，沒有上限。
- 每升一級得到一點，可以加在小幅加成上（掉寶率、元素傷害、生命等），讓刷怪永遠有收穫。

### 6.3 難度與重刷
| 難度 | 解鎖 | 變化 |
|---|---|---|
| 普通 | 一開始 | 劇情難度 |
| 困難 | 通關該章 | 怪物更強、數量更多，物品等級提高 |
| 深淵 | 通關主線 | 怪物帶隨機詞綴，傳說掉率提高 |

### 6.4 終局：深淵裂縫
- 通關主線後開放，是無限層的挑戰關卡。
- 每一層隨機組合場景、怪物和「詛咒詞綴」，例如「敵人死亡時爆炸」、「玩家回血 -50%」。
- 詛咒越多，掉寶越好；層數越高，封印遺物掉率越高。
- 本機排行榜記錄最高層數與最快通關時間。
- **每日裂縫**：依日期產生固定的關卡，每天一次，第一次通關給額外獎勵。

## 7. 探索

- **線性主線加岔路**：每個關卡有主路線，也有隱藏的分支和秘密房間。
- **能力門檻**：學到新招之後，回到舊關卡就能打開新路（見 1.4 的「解鎖的探索能力」）。
- **垃圾堆**：關卡裡可以翻找的地點，翻出隨機物品，偶爾翻出怪。
- **隱藏房間**：放寶箱、稀有殘響、封印遺物，或搞笑彩蛋。例如一位也被召喚來、但已經放棄治療、在深淵開泡麵店的大叔。
- **關卡完成度**：每關顯示寶箱、秘密、遺物的收集百分比，100% 有獎勵。
- **圖鑑**：殘響圖鑑、裝備圖鑑、魔物圖鑑、遺物圖鑑。收集到一定數量會給永久小加成。

## 10. 技術規格

| 項目 | 規格 |
|---|---|
| 技術 | HTML5 Canvas 2D＋JavaScript（ES 模組），不使用遊戲引擎 |
| 內部解析度 | 384×216 像素，整數倍放大到全螢幕，`image-rendering: pixelated` |
| 畫面比例 | 16:9 為主，手機橫向遊玩；其他比例左右或上下補邊 |
| 更新頻率 | 固定 60 次/秒的遊戲邏輯，畫面依裝置刷新率 |
| 特效 | 高頻特效（受擊、死亡、掉落）**預先轉成精靈圖**；大招等低頻特效即時運算 |
| 效能目標 | 中階手機：同時 60 隻敵人、30 個特效、維持 60 fps |
| 效能手段 | 物件池、特效數量上限、畫面外不更新、低效能模式 |
| 存檔 | 瀏覽器本機儲存，自動存檔；可匯出／匯入存檔碼，換裝置時用 |
| 離線 | 做成 PWA，可以加到手機主畫面、離線遊玩 |
| 開發工具 | Node.js（特效預覽、轉精靈圖、打包） |
| 發布 | itch.io 或自架網站 |

## 11. 授權與商用
- PixelFX：MIT 授權，可商用。遊戲內「製作名單」要附上 PixelFX 的授權聲明。
- PixelFX 畫廊中的 Patch Pixel 字體**不在 MIT 範圍內，不使用**。
- 所有外部素材建立一份清單，記錄來源、授權和網址，確保都可以商用。
- 世界觀、角色、劇情為原創；使用常見的異世界題材，但不使用任何特定作品的名稱、角色、劇情或美術。
