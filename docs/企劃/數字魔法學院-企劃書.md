# 《數字魔法學院》企劃書 v0.1

> 2026-11-25 草案。網頁像素小遊戲，數學學習主題。素材全部自己做（pixelfx 程式畫＋pixel-redraw 重畫參考圖），不沿用《轉生成星星碎片的我》的任何角色或場景。

---

## 1. 一句話

見習小巫師在魔法學院裡用「算式咒語」打倒從禁書裡逃出來的墨水怪：**答對就施法，連續答對越多魔法越華麗。**

## 2. 目標與原則

| 項目 | 決定 |
|---|---|
| 對象 | 國小一年級～國中二年級，開頭選難度 |
| 平台 | 網頁（手機直式為主，電腦也能玩） |
| 一局長度 | 3～5 分鐘（一關約 10 題＋王） |
| 學習重點 | **熟練度＋即時回饋**：答錯一定看得到正確算法，錯題自動複習 |
| 不做 | 帳號、排行榜、內購、廣告、計時壓力過大的設計（低年級不限時） |

設計原則：
1. **答題是唯一的操作**——不用邊閃邊答，手機單手就能玩。
2. **答錯不羞辱**：扣心，但「魔法書精靈」會溫柔示範算法。
3. **爽快感來自特效**：連擊越高，同一招會升級成更大的版本。

## 3. 世界觀（輕量）

- **繁星魔法學院**：一所蓋在浮島上的魔法學校，咒語是用數字寫的。
- **事件**：圖書館的禁書《無解之書》被打翻，裡面的「墨水怪」（算錯的算式變成的怪物）跑滿整個學院。
- **主角**：見習生「露米」（可選男／女外觀，同一套動作），魔杖頭是一顆會依元素變色的水晶。
- **夥伴**：魔法書精靈「頁頁」——一本會飛的小書，負責出題、提示和吐槽。介面上的系統台詞都是它說的。
- **反派**：墨水大王「污點」——吸了太多錯誤算式的大墨水團，每個難度最後的王是它的不同型態。

## 4. 難度與題庫

開頭選「學年」，每個學年對應一個**元素學系**與一個**場景**。

| 學年 | 元素 | 場景 | 題型 | 限時 |
|---|---|---|---|---|
| 🌱 一年級 | 🔥 火焰系 | 學院花園 | 20 以內加減、比大小、補數（□＋3＝10） | 不限時 |
| 🌿 二年級 | 💧 水系 | 圖書館 | 100 以內加減（含進退位）、二位數加一位數 | 不限時 |
| 🌳 三～四年級 | ❄️ 冰霜系 | 鐘塔 | 九九乘法、整除、乘除互逆（□×6＝42） | 12 秒（可關） |
| ⭐ 五～六年級 | 🌿 自然系 | 溫室 | 分數加減（同分母→異分母）、小數、四則混合 | 15 秒（可關） |
| 🌙 國中 | ⚡ 雷電系 | 地下禁書庫 | 正負數四則、一元一次方程式、比例 | 20 秒（可關） |

- 題目**用程式產生**，不寫死題庫：每個題型一個產生器（範圍、是否進位、答案不重複），確保四個選項都合理（干擾選項＝常見錯法，例如忘記進位、正負號弄反、分母直接相加）。
- **錯題本**：答錯的題型記在 localStorage，下一局出現機率加倍，連續答對 3 次後移出。
- 每個學年內分 3 小關＋1 王關，小關逐步加難（例如一年級：10 以內 → 20 以內 → 補數 → 王：混合）。

## 5. 核心玩法

### 5.1 畫面配置（手機直式 360×640 邏輯解析度，像素放大）

```
┌──────────────────────┐
│ ♥♥♥      連擊 x5   ★ │  ← 心、連擊、關卡進度
│                      │
│   [背景視差 3 層]     │
│  露米      墨水怪 ←   │  ← 戰鬥區（上 55%）
│  🧙        👾 7+5=?   │     題目掛在怪物頭上
│ ─────────────────────│
│   頁頁：「這題試試…」  │  ← 精靈台詞（一行）
│ ┌────┐ ┌────┐        │
│ │ 12 │ │ 11 │        │  ← 四個答案按鈕（下 45%）
│ └────┘ └────┘        │     電腦可按 1～4
│ ┌────┐ ┌────┐        │
│ │ 13 │ │ 2  │        │
│ └────┘ └────┘        │
└──────────────────────┘
```

### 5.2 一題的流程

1. 墨水怪從右邊慢慢走來，頭上浮著題目（有限時的學年，怪物走到主角面前＝時間到）。
2. 玩家點答案：
   - **答對**：露米揮杖施法（依元素），怪物被打中、化成墨水滴噴散，掉出 1～3 顆「靈感星」（分數）。連擊＋1。
   - **答錯／時間到**：怪物撞上露米，扣 1 顆心，連擊歸零；頁頁跳出**正確算法**（例如「7＋5：先湊 10，7＋3＝10，再加 2＝12」），停 2 秒或點一下繼續。
3. 下一隻怪物登場。

### 5.3 連擊與魔法升級

| 連擊 | 魔法等級 | 例（火焰系） |
|---|---|---|
| 0～2 | 基本 | 小火球（fireball） |
| 3～5 | 強化 | 火焰柱（flame-pillar） |
| 6～9 | 大魔法 | 火焰龍捲（fire-tornado） |
| 10＋ | 終極 | 隕石（meteor）＋全螢幕閃光 |

連擊只影響特效和分數，**不影響難度**——讓「一直答對」本身就是獎勵。

### 5.4 心與失敗

- 每關 3 顆心。心歸零＝「魔力耗盡」，可以選「再試一次」或「回學院」，**不扣任何進度**。
- 一年級、二年級：心歸零後頁頁會說「休息一下，我們換簡單一點的」，自動降一小級題目。

### 5.5 王關

- 墨水大王有**護盾格數**（一年級 3 格 → 國中 6 格），每格要答對一題才打掉。
- 王會出「招式題」：例如連續兩題同類型、或題目會晃動（只做視覺，不影響閱讀）。
- 打倒後學院該區域恢復色彩（場景從灰色墨水污染→彩色），當作過關獎勵畫面。

### 5.6 評分與收集

- 每關結束給 1～3 顆星：答對率 ≥70% ★、≥90% ★★、全對且無錯 ★★★。
- **魔法圖鑑**：每打倒一種墨水怪、每用出一種新等級魔法，就在圖鑑點亮一格。
- **巫師帽收集**：每拿滿一個學年的星星，解鎖一頂帽子（純外觀）。

## 7. 美術製作方式

照現有美術流程與規則：外框只用黑、內線不用黑；色數依類別計（角色 16、雜兵 12、王 24、特效 8、介面 12、場景整關 24）；真像素、剪影清楚、風格一致、動畫不滑步。

| 素材 | 做法 | 參考來源 |
|---|---|---|
| 露米、頁頁、墨水怪、王 | **pixelfx** 程式畫（critters 的形狀＋受光分階畫法），畫→看→修三輪 | 先各找 3 個以上參考（像素巫師、書本生物、墨水史萊姆） |
| 施法特效 | **pixelfx** 現成特效改色／改大小：fire（fireball、flame-pillar、fire-tornado、meteor）、ice（ice-lance、ice-spikes、frost-nova、blizzard-vortex）、lightning（ball-lightning、chain-lightning、lightning-strike）、arcane（arcane-missiles、magic-circle-cast、mana-burst）、holy（heal：答錯回心用）；水系、自然系沒有完整現成組，用現有特效改寫補上 | pixelfx 庫 |
| 怪物死亡、分數拾取 | pixelfx 的 death／pickup 類改成墨水色 | pixelfx 庫 |
| 5 個場景背景（每個 3 層視差＋地面） | **AI 參考圖 → pixel-redraw** 照格子讀回、控色、修外輪廓，給使用者看過才接進遊戲 | 先找多個參考，提示詞記在 `docs/美術/` |
| 介面（按鈕、面板、心、星、連擊數字） | 自己畫像素 UI；按鈕顏色照規則：金＝主要、紅＝危險、紫灰＝一般 | — |
| 字型 | 題目數字用自製像素數字字型（0～9、＋－×÷＝□、分數線），中文用像素風中文字型 | — |
| 音效／音樂 | **sfx-select** 挑選：施法 ×5 元素、答對、答錯、連擊升級、王登場、過關；音樂 3 首（選單、戰鬥、王） | — |

## 8. 技術

- 資料夾：專案根目錄 `math/`（跟 `game/` 並排）。用 Canvas 2D＋ES modules，不用引擎。
- 開發：用現有 `server.mjs` 開，網址 `/math/`。推上後在 GitHub Pages 的 `/math/` 也能玩。
- pixelfx 從 `pixelfx/` 子模組讀；頻繁使用的特效在載入時先烘焙（手機效能）。
- 存檔：localStorage key `math-academy-save-v1`（星星、圖鑑、帽子、錯題本、設定）。
- 設定：音量、限時開關、左手模式（答案按鈕鏡像）、字體放大。

```
math/
  index.html
  src/
    main.js        遊戲迴圈、場景切換
    quiz/          題目產生器（每個題型一個檔）＋錯題本
    battle.js      一題的流程、連擊、心
    boss.js
    ui.js          按鈕、台詞、結算
    save.js
  fx/              自己畫的角色、怪物（pixelfx 格式）
  art/             場景、介面（pixel-redraw 產出）
  audio/
```
